1. The short answer

Your proposed expression mixes a matrix with a vector:

Not valid:

Aβ=Acl−βKek

Aβ and Acl are matrices, but Kek is a vector of switching-instant offsets. They cannot be subtracted.

The conditioning factor scales the switching-instant offset. After that offset enters the one-cycle model through Γτ, the state matrix becomes

A(β)=Φ−βΓτK

2. Where beta is applied

1. Cycle-start error

ek=xk−x⋆

2. Raw LQR offset

δτkraw=−Kek

3. Applied offset

δτkapplied=βkδτkraw

4. Next-cycle error

ek+1=Φek+Γτδτkapplied

Key point: β multiplies the complete raw switching-instant-offset vector. It does not multiply the state matrix directly and it does not replace the LQR gain.

3. From the prediction equation to A(beta)

Start from the linearized prediction equation exactly as written in the note:

e(tN)≐ Φ˜ e(t0)+ Γδt

Define the raw correction using the same input coordinate δt that appears in the prediction equation:

δtraw=−K e(t0)

Apply the conditioning factor to the complete raw correction:

δtapplied=βδtraw =−βK e(t0)

Replace δt in the prediction equation by the applied correction:

e(tN)≐ Φ˜ e(t0)+ Γδtapplied

Substitute δtapplied=−βKe(t0):

e(tN)≐ Φ˜ e(t0)− βΓK e(t0)

Factor e(t0):

e(tN)≐ [Φ˜−βΓK] e(t0)

The dynamic matrix associated with the chosen value of β is therefore

A(β)= Φ˜−βΓK

β = 0

A(0)=Φ˜

β = 1

A(1)=Φ˜−ΓK=Acl

Coordinate requirement: this substitution is direct only when K produces the same δt vector used by Γ in the starting prediction equation.

4. The two endpoint matrices

Define the full raw-feedback closed-loop matrix:

Acl=Φ−ΓτK

Because ΓτK=Φ−Acl, the conditioned matrix can also be written as

A(β)=(1−β)Φ+βAcl

At β = 0

A0=A(0)=Φ

No switching-instant correction is applied. The nominal cycle matrix acts on the error.

At β = 1

A1=A(1)=Acl

The complete raw LQR switching-instant offset is applied.

5. From A(beta) to a common Lyapunov certificate

Use the dynamic error matrix. The strict Lyapunov inequalities below apply to the physical error dynamics. If Φ˜ is the complete augmented transition, its constant final coordinate introduces an eigenvalue at one. Project that coordinate out before asking for strict contraction. In this session, A0 and A1 denote the matrices acting on the dynamic error vector.

1. Name the endpoint matrices

From the beta-dependent matrix obtained previously, define

A0=A(0)=Φ A1=A(1)=Acl

The conditioned matrix is the convex combination

A(β)=(1−β)A0+βA1,0≤β≤1

2. Choose a quadratic Lyapunov function

V(e)=eTPe,P=PT≻0

For one cycle with ek+1=A(βk)ek, the change in the Lyapunov function is

ΔV=ekT [AT(βk)PA(βk)−P] ek

We want one matrix P for which

AT(β)PA(β)−P≺0,∀β∈[0,1]

3. Solve only the endpoint inequalities

With A0 and A1 fixed, the following constraints are linear matrix inequalities in P:

A0TPA0−P≺0 A1TPA1−P≺0

A numerically closed, normalized semidefinite program is

maximizeε overP=PT,ε≥0 subject totr(P)=1 P−εI≽0 P−A0TPA0−εI≽0 P−A1TPA1−εI≽0

If the optimum satisfies ε>0, the solver has found a common quadratic Lyapunov function for both endpoint matrices.

4. Why the endpoints certify every beta

For A(β)=(1−β)A0+βA1, direct expansion gives

(1−β)A0TPA0+βA1TPA1 −AT(β)PA(β) =β(1−β)(A0−A1)TP(A0−A1)≽0

Therefore

AT(β)PA(β) ≼(1−β)A0TPA0 +βA1TPA1

If both endpoint terms contract the same quadratic function, every convex combination does too. The same P then proves decrease for every β∈[0,1], including a different state-dependent βk on each cycle.

5. YALMIP form of the convex program

n = size(A0, 1);
P = sdpvar(n, n, 'symmetric');
epsilon = sdpvar(1);
I = eye(n);

constraints = [
    trace(P) == 1,
    epsilon >= 0,
    P - epsilon*I >= 0,
    P - A0'*P*A0 - epsilon*I >= 0,
    P - A1'*P*A1 - epsilon*I >= 0
];

options = sdpsettings('solver', 'sedumi', 'verbose', 0);
result = optimize(constraints, -epsilon, options);

P_value = value(P);
epsilon_value = value(epsilon);

Offline computation: the semidefinite program computes P once during analysis or controller design. The online conditioner still computes only βk and scales the raw switching-instant offset.

6. Why the two endpoints are enough

The endpoint argument is correct only when the optimization finds one positive-definite matrix P that works for both Φ and Acl.

1. Fix one quadratic Lyapunov function

Define

V(e)=eTPe,P=PT≻0

For this fixed P, define the contraction set

𝒞P={A:ATPA−P≺0}

Every matrix in 𝒞P decreases the same Lyapunov function. This fixed-P set is convex.

2. Put both endpoints in that same set

Use the physical one-cycle error matrices

A0=Φ A1=Acl

The semidefinite optimization must impose both inequalities on the same decision matrix P:

ΦTPΦ−P≺0 AclTPAcl−P≺0

Because Φ and Acl are fixed, these are linear matrix inequalities in P. Finding P subject to both is a convex feasibility problem.

3. Verify an arbitrary point on the segment

For

A(β)=(1−β)Φ+βAcl,0≤β≤1

direct expansion gives

(1−β)ΦTPΦ+βAclTPAcl −AT(β)PA(β) =β(1−β)(Φ−Acl)TP(Φ−Acl)≽0

It follows that

AT(β)PA(β) ≼(1−β)ΦTPΦ+βAclTPAcl ≺P

Therefore

AT(β)PA(β)−P≺0,∀β∈[0,1]

4. What the certificate proves

  • Every matrix on the segment is Schur stable.
  • The same quadratic function V(e)=eTPe decreases for every point on the segment.
  • The linearized system remains exponentially stable when βk changes from cycle to cycle.

5. What would not be enough

Endpoint stability alone is insufficient. The set of all Schur-stable matrices is not generally convex. Likewise, finding one matrix P0 for Φ and a different matrix P1 for Acl does not certify the matrices between them. The shared P is the essential part of the argument.

This certificate applies to the physical one-cycle linearized error model. It does not by itself establish global stability of the exact nonlinear switched-affine plant.

8. Why the original expression fails

The dimensions identify the missing operation.

QuantityMeaningDimension
ekCycle-start state errorn×1
KLQR gain(N−1)×n
KekRaw timing-offset vector, apart from its minus sign(N−1)×1
ΓτSwitching-instant sensitivityn×(N−1)
ΓτKTiming-feedback contribution to the cycle matrixn×n
Φ,A(β),AclOne-cycle state matricesn×n

The required matrix term is ΓτK. The multiplication by Γτ converts the timing-offset vector produced by the LQR law into a state-error change.

9. When beta changes each cycle

The dwell-time conditioner normally computes βk from the current raw offset and the available dwell margins. Its value can therefore depend on the current cycle-start error.

ek+1=A(βk)ek

On every cycle, the selected matrix remains on the segment joining Φ and Acl. The selected point may move along that segment from one cycle to the next.

This matrix-segment statement belongs to the one-cycle linearized model. It is not, by itself, a global statement about the exact nonlinear plant.
