Solving cvx_example.m by hand

The MATLAB file contains a small linear program. CVX solves it numerically, but the exact solution follows directly from substitution.

1. Read the optimization problem

The code asks us to minimize the linear objective

minimize   x1 + 2x2

subject to

x1 + x2 = 1,    x1 ≥ 0,    x2 ≥ 0.

Step 1: Use the equality constraint

Solve the equality for x2:

x2 = 1 - x1.

Step 2: Find the allowed range

The nonnegative constraints restrict the remaining variable:

0 ≤ x1 ≤ 1.

The first inequality comes from x1 ≥ 0. The second comes from x2 = 1 - x1 ≥ 0.

Step 3: Substitute into the objective

Replace x2 with 1 - x1:

f(x1) = x1 + 2(1 - x1) = 2 - x1.

This expression decreases as x1 increases. Therefore, its minimum over 0 ≤ x1 ≤ 1 occurs at x1 = 1.

Step 4: Recover the other variable

x2 = 1 - 1 = 0.

Solution

x* = [1, 0]T    and    f* = 1.

The point [1, 0]T satisfies the constraint because 1 + 0 = 1, and both variables are nonnegative.

Geometric interpretation

The equality x1 + x2 = 1, together with nonnegativity, produces a line segment from (1, 0) to (0, 1). Since the objective is linear, the minimum occurs at an endpoint.

Feasible point Objective value
(1, 0) 1 + 2(0) = 1
(0, 1) 0 + 2(1) = 2

The first endpoint is better because one unit of x1 costs 1, while one unit of x2 costs 2.

Connection with the MATLAB code

cvx_begin
    variable x(2)
    minimize(x(1) + 2*x(2))
    subject to
        x(1) + x(2) == 1
        x >= 0
cvx_end

What the checks verify

The file expects

x = [1, 0]T,    cvx_optval = 1.

The assertions compare CVX's numerical result with this hand-derived solution, allowing a small tolerance of 10-6 for numerical error.
