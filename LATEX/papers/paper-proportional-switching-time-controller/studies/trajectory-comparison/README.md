# Standalone trajectory comparison

Run `task trajectory-comparison` from the paper root. [generate_comparison.m](generate_comparison.m) generates the four PDFs in [results/](results/).

This study compares controller-on/off continuous-time trajectories and long-horizon open-loop convergence. It uses the sibling MATLAB model and the paper's dwell conditioner. Its original outputs remain separate from `task results`.

The manuscript now includes a publication version generated by [`paper.export_trajectories`](../../scripts/+paper/export_trajectories.m). That version reuses the article's benchmark and simulation arrays, checks dense propagation against every cycle end, and writes publication data under `results/` at the paper root. Unlike page 2 of this standalone study's `trajectory_comparison.pdf`, the article's 3D comparison uses dense within-interval samples, not only switching-boundary polygons.

The script and outputs were moved together from `scripts/generate_trajectory_comparison.m` and `comparison/`. Its numerical method has not been refactored in this organization pass.
