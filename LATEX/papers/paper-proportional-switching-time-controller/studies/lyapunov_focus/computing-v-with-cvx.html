Studies · Lyapunov · A first certificate

Computing a Lyapunov function with CVX

One system, one method, one conclusion. We take a damped mass on a spring, try the Lyapunov function that physics suggests, watch it fall just short, then ask a solver for one that works. By the end you will have proved that the system is asymptotically stable, and you will know exactly what that proof does and does not say.

What you need

Matrices, eigenvalues, and the idea of a differential equation. Nothing about optimization. MATLAB with CVX installed; run cvx_example first if you want to be sure it works.

The script

studies/lyapunov/damped_oscillator_cvx.m produces every number below. Read the page first, then run it and watch the same numbers appear.

1 · The system

A mass on a spring, with a damper

A block of mass m sits on a frictionless surface, tied to a wall by a spring of stiffness k, with a damper of coefficient c resisting its motion. Pull it aside, let go, and it oscillates while slowly losing amplitude. That much you already know. Our job is to prove it settles, using a method that will still work on systems where your intuition has nothing to offer.

Newton's second law gives mẍ + cẋ + kx = 0. To work with it we rewrite the one second-order equation as two first-order ones. Call the position x1 and the velocity x2:

x˙1 =x2 x˙2 =−km⁢x1−cm⁢x2

Stack the two states into a vector x = (x1, x2) and this is just ẋ = Ax. With m = 1 kg, c = 0.4 N·s/m and k = 4 N/m,

A= [ 01 −4−0.4 ]

The state x = 0 means the block sits at rest at the spring's natural length. That is the equilibrium, and it is the point we want to prove the system returns to.

A shortcut we are deliberately not taking

For a linear system ẋ = Ax there is a one-line answer: the equilibrium is asymptotically stable exactly when every eigenvalue of A has negative real part. Here the eigenvalues are −0.2 ± 1.99i, so we are done.

We are going to ignore that and do it the long way, because the eigenvalue test stops working the moment the system stops being one fixed linear map. Lyapunov's method keeps working, and this is the smallest system on which you can learn it properly.

2 · The idea

What a Lyapunov function is, and why one is enough

Simulating from one starting point tells you about that starting point. Lyapunov's idea replaces the simulation with a single scalar quantity that is forced to shrink.

Find a function V(x) with two properties:

  1. It is a valid measure of distance from the target. V(0) = 0, and V(x) > 0 for every other x.
  2. It always decreases. Along every solution of the differential equation, the time derivative V̇(x) is strictly negative for every x ≠ 0.

If such a V exists, the equilibrium is asymptotically stable. The reasoning is short: V can never increase, so the state can never escape outward; and because V is strictly decreasing and cannot go below zero, it has nowhere to end up except zero, which happens only at x = 0.

Notice what that argument did not require. It never solved the differential equation. It never simulated anything. It checked a condition at each point of the state space and concluded something about all trajectories at once. That is the whole reason the method scales to problems where solving is hopeless.

Choosing the shape of V

“Find a function” is a very large search. We shrink it by deciding in advance that V is a quadratic form:

V(x)=x⊤Px with P symmetric

For our two-state system that is just V = P11x1² + 2P12x1x2 + P22x2². The unknown is no longer a function. It is three numbers.

Requirement 1 becomes a familiar condition: V > 0 away from the origin means P is positive definite, written P ≻ 0, which for a symmetric matrix means all its eigenvalues are positive.

Requirement 2 needs the derivative. Using ẋ = Ax and the product rule,

V˙ = x˙⊤Px+x⊤Px˙ = (Ax)⊤Px+x⊤P(Ax) = x⊤(A⊤P+PA)x

So V̇ is itself a quadratic form, built from the matrix AₜP + PA. Requiring it to be negative for all x ≠ 0 means that matrix is negative definite, written ≺ 0, meaning all its eigenvalues are negative.

The whole problem, in two lines

Find P=P⊤ such that P≻0and A⊤P+PA≺0

Everything from here on is about finding such a P. Section 3 guesses one. Section 4 computes one.

What P means geometrically

The set of points where V(x) equals some constant is an ellipse, centred on the origin. Different P give differently shaped and differently tilted ellipses. So choosing P is choosing what “far from the equilibrium” means, and requirement 2 says the trajectory must cross every one of those ellipses strictly inward. You will see this in the laboratory in section 5.

3 · The obvious guess

Physics offers a candidate, and it falls just short

For a mechanical system there is a natural guess: the stored energy. Kinetic plus potential,

E(x)=12⁢k⁢x12 +12⁢m⁢x22 =2⁢x12+0.5⁢x22

which is a quadratic form with

Penergy= [ 20 00.5 ]

It is clearly positive definite: eigenvalues 2 and 0.5, both positive. Requirement 1 holds. Now test requirement 2 by forming AₜP + PA:

A⊤Penergy+PenergyA= [ 00 0−0.4 ]

Its eigenvalues are 0 and −0.4. One of them is zero, so this matrix is negative semidefinite, not negative definite. Requirement 2 fails.

Why it fails, physically

Read the matrix back as a formula: Ė = −0.4 x2², that is, Ė = −c v². The only thing removing energy from this system is the damper, and the damper only does work when the mass is moving. At the top of each swing the mass is momentarily at rest, x2 = 0, and at that instant the energy is not decreasing at all.

So the zero is not a numerical artefact and it is not a mistake in the guess. It is a true statement about the physics, and it means the energy is not quite a Lyapunov function in the strict sense we asked for.

Is the system therefore not stable?

No. The energy argument still proves the system is stable (it never runs away). It just does not prove it is asymptotically stable (it actually converges). There is a classical repair called LaSalle's invariance principle, which reasons about where the trajectory can linger while Ė = 0 and recovers the stronger conclusion.

We are going to take the other road: rather than patch the argument, change the ruler. Ask for a P that satisfies the strict condition outright. And rather than guess again, compute one.

4 · Computing V

Why a solver can do this, and how to ask

Look hard at the two requirements:

P≻0 A⊤P+PA≺0

The unknown P appears linearly in both. No P multiplied by P, no P inverted, no square roots. A constraint saying “this matrix, which depends linearly on the unknowns, is positive definite” is called a linear matrix inequality, or LMI.

That is the fact that makes the whole thing computable. The set of P satisfying an LMI is convex: if two matrices both work, everything on the line between them works too. Convex problems have no local traps for a solver to fall into. An interior-point method walks into the set from anywhere, or reports that the set is empty. And “empty” is a real answer, not a failure: it means no quadratic V exists for this system, so you would need a different shape of V.

CVX is a MATLAB layer that lets you type constraints roughly as you would write them and hands the problem to a solver. Here is the whole thing.

% studies/lyapunov/damped_oscillator_cvx.m
A = [0 1; -4 -0.4];
n = size(A, 1);

cvx_begin sdp quiet
    variable P(n, n) symmetric
    minimize(0)                                     % feasibility only
    subject to
        P - eye(n) == semidefinite(n);              % P >= I
        -(A'*P + P*A) - eye(n) == semidefinite(n);  % A'P + PA <= -I
cvx_end

P = (P + P')/2;   % symmetrise what the solver returned

Reading that code line by line

cvx_begin sdpopens a CVX problem in semidefinite mode, so matrix inequalities are understood as definiteness constraints rather than entry-by-entry comparisons. quiet just suppresses the solver log.
variable P(n,n) symmetricdeclares the unknown. Saying symmetric matters: it tells CVX there are three unknowns here, not four, and it keeps the problem well posed.
minimize(0)we are not optimizing anything yet. We only want to know whether a feasible P exists, so the objective is a constant.
== semidefinite(n)CVX's way of writing “this expression is positive semidefinite”. P - eye(n) == semidefinite(n) therefore says P − I ⩽ 0, that is, P ⩾ I.

Why I and not 0

The mathematics asks for strict inequalities, P ≻ 0 and AₜP + PA ≺ 0. Solvers work to a numerical tolerance and cannot honour a strict inequality, so we ask for something slightly stronger that they can honour: P ⩾ I and AₜP + PA ⩽ −I. Any P meeting those certainly meets the strict versions, with room to spare.

Using I costs nothing, because of a small piece of good luck: if P works then so does 10P, since both conditions are homogeneous. Scaling a certificate up never breaks it. So demanding a margin of exactly I rules out no system.

What comes back

So the Lyapunov function is

V(x)=14.5465⁢x12 +2(0.6097)⁢x1⁢x2 +3.7280⁢x22

Compare that with the energy, which was 2x1² + 0.5x2². The solver's answer weights position much more heavily, and it has a nonzero cross term x1x2, which the energy did not. That cross term is what tilts the ellipses, and the tilt is exactly what removes the flat spot.

Your numbers will probably differ

There are infinitely many valid P, and which one a solver lands on depends on the solver, its tolerances, and its starting point. If you run the script and get different digits, nothing is wrong. Check yours the way section 5 does; if it passes, it is just as good a proof as this one.

5 · Verification

Checking the certificate yourself

Never take the solver's word for it. A conic solver returns an approximate answer to a tolerance, and the whole value of a Lyapunov certificate is that the final check is cheap and exact. Two eigenvalue computations:

P = (P + P')/2;                 % symmetrise first, always
eig(P)                          % must be all positive
S = A'*P + P*A;  S = (S + S')/2;
eig(S)                          % must be all negative
CheckResultVerdict
eigenvalues of P3.6937, 14.5807both positive, so P ≻ 0
eigenvalues of AₜP + PA−4.9922, −1.6481both negative, so V̇ ≺ 0
same, for the energy−0.4000, 0.0000a zero, so not strict
cond(P)3.9474ellipses are mildly stretched

Both requirements hold, with margin. The equilibrium of this system is asymptotically stable, and that is now proved, not observed.

Why symmetrise before testing? The matrix CVX returns is symmetric only to within its tolerance, and eig on a very slightly non-symmetric matrix can return complex numbers with tiny imaginary parts, which then confuse every comparison you make afterwards. One line prevents an hour of confusion.

6 · Going further

Getting a speed out of the certificate

So far we have proved the system converges. We have not said how fast. A small change to the second constraint answers that too. Ask for

A⊤P+PA⪯−2αP

instead of ⩽ −I. Written out, this says V̇ ≤ −2αV, and a scalar quantity obeying that inequality satisfies V(t) ≤ V(0)e−2αt. Since V is a quadratic form pinched between λmin(P)‖x‖² and λmax(P)‖x‖², that turns into a bound on the state itself:

‖x(t)‖≤ cond(P) ⋅e−αt⋅ ‖x(0)‖

One wrinkle: with both P and α unknown, the term 2αP is a product of two unknowns, so the problem is no longer linear. The standard fix is to fix α, which makes it an LMI again, and search over α from the outside by bisection. That is what the script does, forty halvings of an interval.

lo = 0; hi = 5;
for iteration = 1:40
    mid = (lo + hi)/2;
    if rate_feasible(A, mid)   % one CVX solve at this fixed alpha
        lo = mid;                % it worked, try faster
    else
        hi = mid;                % too fast, back off
    end
end
best certified alpha   0.200000
-max(real(eig(A)))     0.200000
difference             2.73e-08   (they agree, as they must)

so ||x(t)|| <= 2.017 * exp(-0.1998 t) * ||x(0)||

The bisection lands on α = 0.2, which is exactly minus the real part of the eigenvalues of A. That agreement is worth pausing on. It is a good sanity check that the machinery is correct, and it also tells you the method is not throwing anything away here: for a single linear system, the best rate a quadratic V can certify is the true decay rate, no worse.

The factor 2.017 in front is √(cond P). It is the price of measuring with tilted ellipses instead of circles, and it is why the bound allows the state to grow briefly before it settles, even though V itself never does.

7 · Closing

What you proved, and what comes next

The recipe, in five steps

  1. Write the dynamics as ẋ = Ax with the equilibrium at the origin.
  2. Decide V(x) = xₜPx, so the unknown is a matrix.
  3. Write the two requirements as LMIs: P ⩾ I and AₜP + PA ⩽ −I.
  4. Hand them to CVX.
  5. Check the returned P yourself with two eig calls.

The honest boundary

What is proved: the origin of this system is asymptotically stable, and every solution satisfies ‖x(t)‖ ≤ 2.017 e−0.2t‖x(0)‖. What is not proved: anything about a different A, anything about the real block once you include friction that is not linear, and anything about how the system behaves when something pushes on it. A Lyapunov certificate is a statement about one specific model, and it is worth saying out loud which one.

Also worth naming: on this example the eigenvalue test in section 1 would have answered the question in one line, and it would have been right. Nothing here beat it. The reason to learn the long way is what happens when the one-line test stops applying.

Where this goes

  • Discrete time. If the model steps rather than flows, xk+1 = Axk, the same derivation gives AₜPA − P ≺ 0. Same code, one line changed.
  • Several possible dynamics. If the system switches between A1 and A2 in a way you do not control, ask for one P that satisfies the decrease condition for both. This is where the method earns its keep, because eigenvalues genuinely cannot answer it: two stable matrices can switch into an unstable system.
  • Design, not just analysis. With a control input the same machinery, after a change of variables, finds a stabilising gain and its certificate together.

The second of those is the subject of the longer study in this folder, lyapunov-convex-optimization.html, which builds a case where every guess you would make by hand provably fails, and then applies the same idea to the switching-time controller in the paper. Read this page first.
