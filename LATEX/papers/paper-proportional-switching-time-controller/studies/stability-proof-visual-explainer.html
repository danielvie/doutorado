Stability proof · Proposition 2 of the paper

One norm, every path

Why a single Lyapunov matrix P certifies the conditioned closed loop A(β) = (1−β)Φ + βAcl for every conditioning sequence the plant can generate — and why the popular mental model “two optimizations, both stable, same convex space” gets the mechanism wrong in three places. Four steps, each followed by a laboratory you can drive yourself, and a geometric reading of which convex set the argument actually leans on.

STEP 1

Conditioning traces a segment between two matrices

The conditioner never redirects the raw feedback action δτraw = −Kek. It multiplies the whole vector by one scalar βk ∈ [0,1] — the largest scalar that keeps every dwell duration above dmin. Direction, mode order, and cycle period are untouched; only magnitude is given up.

In the linearized cycle model this scalar shows up as a convex combination of two fixed matrices:

ek+1 = A(βk)ek,  A(β) = (1−β)Φ + βAcl

Mental-model correction #1. The two endpoints are not “found by two optimizations.” Φ and Acl come straight from the plant model and the LQR gain. The only thing any optimization ever searches for is P — next step.

STEP 2

One SDP finds one P that contracts both endpoints

A single offline semidefinite program searches for one matrix P = P⊤ ≻ 0 satisfying both endpoint conditions at once:

‖Φ‖P ≤ q0 < 1 and ‖Acl‖P ≤ q1 < 1

Geometrically, P defines one family of ellipsoidal level sets {e : e⊤Pe = c}. The two conditions say: whichever endpoint map you apply, a state on the ellipsoid lands strictly inside a shrunken copy of the same ellipsoid.

Mental-model correction #2. “Both are stable” is necessary but not sufficient. The hypothesis is stronger: both endpoints contract in the same P-norm. Each matrix being Schur on its own would give you two different Lyapunov ellipses — and that, as Step 4 shows, proves nothing about the path. This is also why the certificate demands ‖Φ‖P < 1: the open-loop cycle must already be stable, or no common P exists.

STEP 3

Convexity of the norm carries contraction along the segment

Here is the actual mechanism behind “the path is stable” — not membership in a shared space, but the triangle inequality of the induced norm. For any β ∈ [0,1]:

‖A(β)‖P ≤ (1−β)‖Φ‖P + β‖Acl‖P ≤ (1−β)q0 + βq1 ≤ q ≔ max(q0, q1) < 1

Mental-model correction #3. “Same convex space” is close but hides the trap: stability itself is not a convex property. A segment between two Schur matrices can pass through unstable matrices in the middle. What is convex is contraction in one fixed norm — and that is exactly why the proof needs the common P from Step 2 before convexity is allowed to do any work.

GEOMETRY

Which convex set is doing the work

Lab 3 leaves a fair question hanging. If a straight line between two stable matrices can pass through unstable ones, what exactly makes our line safe? The tempting answer is “both endpoints are in the same convex space, so the whole segment is too.” That answer is correct — but only once you name the set, and the set is not the one most people have in mind.

Fix P and q and collect every matrix that contracts by q in that norm:

ℬ = {A : ‖A‖P ≤ q}

This set is convex, for the most ordinary reason available: it is a ball of a norm, and norm balls are always convex. Convexity of ℬ and the triangle inequality of Step 3 are not two facts — they are the same fact, once written geometrically and once written algebraically.

Now the piece that makes the picture click. For any induced norm, ρ(A) ≤ ‖A‖P. So if q < 1, every matrix in ℬ is Schur, which means each choice of P carves out a convex blob sitting inside the stable set. The stable set itself is an awkward, non-convex region; a P-norm ball is a well-behaved convex body inside it. There are many such blobs, one family per P, and none of them fills the region.

Read the semidefinite program in those terms and it stops being an algebraic ritual: its only job is to find one blob that holds both endpoints. Once it does, the segment from Φ to Acl is trapped inside that blob, and the blob is inside the stable set. Stability of the interior is never argued directly — it is inherited from the containment.

This is also the sharpest way to see why two separate Lyapunov matrices are worth nothing here. Two matrices give you two blobs, each certifying its own endpoint. Two blobs say nothing whatsoever about the line strung between them, because the region they both live in is not convex. Only when a single blob covers both does the segment come along for free.

One caveat, so the picture is not stronger than the theorem. The implication runs one way: a common P is sufficient for the segment to be stable, not necessary. There are pairs whose segment happens to stay stable with no common P to be found. What the certificate buys is not the weakest possible hypothesis — it is a hypothesis you can actually verify offline, with a solver, once.

Why the path is straight, and why that matters

Convexity is exactly the property “closed under straight segments,” so the argument needs the path between the endpoints to be a straight one. It is, and that traces back to a design decision in the conditioner: because βk multiplies the entire offset vector by one scalar, the reachable matrices form a line.

It is worth seeing what the alternative would have cost. Had the offsets been clipped one at a time, the applied action would be diag(c1,…,cN−1)δτraw and the closed loop would be Φ − Γτ diag(c)K, which is still affine in c — so the reachable family would be a polytope rather than a segment. Convexity would still do its job, and the same argument would still work. But the certificate would have to hold at every vertex of that polytope: 2N−1 = 256 linear matrix inequalities for the nine-interval benchmark, instead of two. Scalar conditioning collapses the corner count to a pair of endpoints. That is a second, independent argument for scaling the whole vector, alongside the direction-preservation argument the paper makes.

Keep two payoffs apart. Convexity of ℬ is what gets you from the two endpoints to every A(β) on the segment. That alone would still not survive a changing βk — for that you need it to be the same ℬ every cycle, which is what Step 4 spends. One matrix P, two distinct jobs.

STEP 4

The common norm is what survives arbitrary switching

The plant does not sit at one fixed β. The conditioner emits a state-dependent sequence β0, β1, β2, … — a different matrix every cycle. For switched systems this is where naïve arguments die: even a family in which every individual matrix is stable can diverge under the wrong switching sequence, because each map’s “shrink” is measured in a different geometry.

With the common P of Step 2 and the segment bound of Step 3, every cycle multiplies the P-norm of the error by at most q = max(q0, q1) < 1, regardless of which βk the conditioner picked:

‖ek‖P ≤ qk ‖e0‖P for every sequence {βk} ⊂ [0,1]

That single line is the payoff of the whole construction: exponential stability of the conditioned linearized loop under arbitrary, state-dependent conditioning — no need to know, model, or bound which cycles saturate.

RECAP

The mental model, corrected

  • ✗“Two convex optimizations: one finds P for β=1, another finds Acl for β=0.”  →  One SDP, one unknown: a single P constrained by both endpoint inequalities simultaneously. Φ and Acl are data, not decision variables.
  • △“Then there is proof that both are stable, within the space defined by the same P.”  →  Right instinct, wrong strength: both must contract in the same P-norm, which is strictly stronger than both being stable. It also forces the open loop Φ to be stable — a real restriction of the method.
  • △“The path is stable since they belong to the same convex space.”  →  Right, once the set is named. It is the norm ball {A : ‖A‖P ≤ q}, a convex blob inside the stable set — not the stable set itself, which is not convex, as Lab 3 shows. Both endpoints in one blob traps the segment inside it.
  • ✓The piece the model missed: βk changes every cycle. The common norm is what upgrades “each A(β) is fine” to “every sequence of them is fine” — the actual claim the plant needs, and the one Lab 4 breaks when the common norm is absent.

One-line version. One SDP finds one P making both segment endpoints contractions in ‖·‖P; norm convexity extends the contraction to the whole segment; the shared norm extends it to any time-varying sequence βk.
