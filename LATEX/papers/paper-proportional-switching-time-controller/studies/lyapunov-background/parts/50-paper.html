5 · Stability proof of the switching-time controller

Certifying a closed loop whose gain is rescaled at runtime

Everything so far has been preparation for one specific difficulty. The paper’s controller computes a correction, then discovers the correction is physically inadmissible, then shrinks it by a factor decided at runtime from the state. The loop gain is therefore not a constant. It is not even a known sequence. It is a state-dependent scalar that changes every cycle.

The usual reflexes both fail here. You cannot check eigenvalues, because there is no fixed matrix to take eigenvalues of. You cannot simulate your way to a guarantee, because the sequence of gains is uncountable. What is left is a Lyapunov certificate, and it works for the reason given in §2.6, applied to a family of exactly two vertices.

5.1  The object being stabilized: the cycle-start error

The plant is a switched-affine converter that runs a fixed sequence of nine mode intervals, every cycle, forever:

ẋ(t) = Aσx(t) + bσ,    σ drawn from a prescribed nine-interval sequence of period T.

Under the nominal schedule the state traces a periodic trajectory. Sample it once per cycle, at the cycle boundary, and that periodic trajectory collapses to a single point, the cycle anchor x⃗, which is a fixed point of the one-cycle map. Stabilising the limit cycle means driving the cycle-start error ek = xk − x⃗ to zero.

5.2  The linearized one-cycle model

Propagating each interval with an exact augmented matrix exponential and expanding to first order in the interval durations gives a plain linear map from one cycle boundary to the next:

ek+1 = Φek + Γτδτk + higher-order terms,

where δτk ∈ ℝ⁸ holds the eight switching-instant offsets. In the normalised coordinates the paper designs in,

The open-loop cycle map is stable, but barely: an error decays by 0.015 % per cycle, and takes {{metrics.OpenLoopConvergenceCycle}} cycles to fall below the paper’s settling threshold. That number matters later, because it is what sets the certificate’s contraction bound.

5.3  The dwell constraint and the conditioning factor β

A static law δτrawk = −Kek, here an LQR gain, knows nothing about time. The physical constraint is on the nine dwell durations, and moving one boundary changes the two dwells on either side of it:

δd = Dδτ,   δdi = δτi − δτi−1,    d̄ + Dδτ ≥ dmin1.

Because the columns of D sum to zero, any offset vector preserves the period exactly. What it does not preserve is admissibility. From the paper’s large-error initial state, the aggressive gain requests offsets up to {{metrics.MaximumRawOffset}} µs and a dwell of {{metrics.MinimumRawDwell}} µs. It is negative, so two boundaries have swapped places and one mode interval has been turned inside out. That schedule cannot be executed.

Clipping the offending components one at a time would fix the dwells and change the direction of the correction, which is the thing the gain was designed to get right. The paper does the opposite: it keeps the direction and gives up magnitude, scaling the entire vector by the largest single factor that restores admissibility,

βk = min{ 1,  mini : qi < 0 mi / (−qi) },    qk = Dδτrawk,   m = d̄ − dmin1,

and applies δτappk = βk δτrawk. One pass over nine numbers; no solver.

5.4  The conditioned closed loop is a line segment

Substitute the applied action into the linearized model:

ek+1 = Φek − ΓτβkKek = [(1 − βk)Φ + βkAcl]ek,    Acl = Φ − ΓτK.

The scalar came out. Whatever the conditioner decides, the closed-loop matrix for that cycle is a point on the line segment joining two fixed matrices: Φ at β = 0, where the correction is switched off entirely, and Acl at β = 1, where it is applied in full. A continuum of possible gains, but a one-dimensional continuum with two endpoints, and §2.6 says two endpoints is all a common P needs.

That is a consequence of scaling by one number. Had the conditioner clipped components independently, the applied action would be Λδτraw with Λ diagonal, and the reachable set of closed-loop matrices would be a polytope with 2⁸ = {{polytope.vertex_count|d}} vertices instead of a segment with two. §5.7 shows what that would have cost.

5.5  Proposition 2: contraction of the whole family

Proposition 2 (common-Lyapunov contraction)

Let P = Pₜ ≻ 0 and suppose ‖Φ‖P ≤ q0 < 1 and ‖Acl‖P ≤ q1 < 1. Then every A(β) with β ∈ [0,1] contracts in the same norm by at most q = max(q0, q1) < 1, so the conditioned linearized model is exponentially stable for every sequence {βk} ⊂ [0,1], including the state-dependent sequences the conditioner actually generates.

Proof. By the triangle inequality for the induced norm, ‖A(β)‖P ≤ (1−β)q0 + βq1 ≤ q < 1. Hence ‖ek‖P ≤ qk‖e0‖P for any sequence. ∎

Notice what the proof does not need. It never assumes β is constant, slowly varying, known ahead of time, or independent of the state. It never needs Φ and Acl to commute. It does not need a dwell-time condition on how long the loop stays at any particular β. All of that is bought by the bound being a statement about one step in a norm that does not depend on which matrix was applied.

And notice what it does need: a common P for both endpoints. In particular ‖Φ‖P < 1, which is a real hypothesis. The uncontrolled cycle map has to be contracting in the same norm. If the open loop were unstable there would be no such P, the conditioner would still run and would still return an admissible schedule, and only the guarantee would be lost. The paper states this restriction rather than burying it.

The bound is set by the open-loop endpoint, not the closed-loop one, and it is {{paper.q0|.6f}}, a contraction but only just. This is worth being blunt about, because it is easy to over-read a Lyapunov result. The certificate covers the worst conceivable conditioning sequence, and the worst conceivable sequence is βk ≡ 0: a controller that never corrects anything. Nothing can be promised beyond what the open loop does on its own, because the open loop is a member of the family. The bound is a guarantee of stability, not a prediction of performance.

The observed behaviour is a different question with a much better answer. Once βk returns to 1, after {{metrics.ConditionedCycleCount}} cycles, the loop contracts at ρ(Acl) = {{paper.rho.1|.6f}} per cycle, and the run settles at cycle {{metrics.ConditionedSettlingCycle}} against cycle {{metrics.ConservativeSettlingCycle}} for the conservative law that never needed conditioning at all.

5.7  Comparison with per-component clipping

The claim in §5.4, that uniform scaling is what makes the family certifiable, is checkable, so here it is checked. Replace the scalar β by a diagonal Λ ∈ [0,1]⁸, one factor per offset. The closed loop becomes Φ − ΓτΛK, and by multilinearity in the diagonal entries the reachable set is the polytope spanned by the {{polytope.vertex_count|d}} vertices with every λi ∈ {0, 1}. 5.8  The local nonlinear statement, and its limits

Everything above is a statement about A(β), which is a linearization. The paper is explicit that the exact nonlinear guarantee is weaker, and local. The argument runs: δτraw(0) = 0, and the nominal schedule keeps a strict dwell margin, so by continuity there is a neighbourhood of the anchor in which the raw action is already admissible and the conditioner never fires. Inside it β ≡ 1, the Jacobian of the exact closed-loop map is Acl, and Acl is Schur. So the anchor, and the phase-locked periodic trajectory through it, are locally exponentially stable for the exact map.

Outside that neighbourhood Proposition 2 still covers arbitrary conditioning, but only for the linearized model. It does not bound the nonlinear remainder, and it is not a global result. The hundred-cycle converter run from a large initial error is evidence, not proof, and the paper labels it that way.

The run is still worth seeing against the envelope, because the gap between them is the point.
