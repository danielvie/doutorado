2 · Lyapunov theory for discrete-time systems

From the direct method to a linear matrix inequality

2.1  The direct method in discrete time

Everything in this study is discrete time, because the object the paper stabilizes is a cycle-to-cycle map. Take

xk+1 = f(xk),   f(0) = 0.

Suppose a continuous function V satisfies V(0) = 0, V(x) > 0 for x ≠ 0, and

V(f(x)) − V(x) < 0  for all x ≠ 0.

Then the origin is asymptotically stable. If in addition V(f(x)) ≤ q²V(x) for some q < 1, convergence is exponential at rate q. Nothing in the statement mentions trajectories: you check an inequality pointwise, and the trajectories follow.

2.2  Quadratic Lyapunov functions, and the role of P

Choose V(x) = xₜPx with P symmetric and positive definite. Positive definiteness is exactly the “positive except at the origin” requirement, and the level sets {x : xₜPx = c} are ellipsoids. So P fixes what counts as distance: it decides which directions in the state space are treated as far from the origin. This study calls it the ruler for short. P = I is the Euclidean ruler, the one that treats every direction alike. It is one candidate among infinitely many, and there is no reason for a given system to respect it.

For a linear map xk+1 = Axk the decrease condition becomes

V(Ax) − V(x) = xₜ(AₜPA − P)x < 0  for all x ≠ 0,  i.e.  AₜPA − P ≺ 0,

where ≺ 0 means “negative definite”. Two matrix inequalities, then: P ≻ 0 and AₜPA − P ≺ 0.

2.3  Why the two conditions form a convex feasibility problem

Look at what the unknown does. In AₜPA − P, the matrix P appears linearly. There are no products of unknowns and no inverses. A constraint of the form “this symmetric matrix, which depends affinely on the decision variables, is negative definite” is a linear matrix inequality, and the set of decision variables satisfying it is convex. Intersecting several of them, one per mode, keeps it convex.

That is the entire reason this works. A convex feasible set has no local minima to get stuck in and no isolated islands to miss. An interior-point solver either walks into it or returns a certificate that it is empty, and “empty” is a real answer: it means no quadratic Lyapunov function exists for that family, not that you failed to find one.

2.4  Scale normalisation and strict inequalities

Scale is free. If P works, so does 10P: both inequalities are homogeneous. So a solver asked to “maximise the decrease” will happily blow P up without end. Pin the scale down, usually with trace(P) = n, and the problem becomes bounded. This changes nothing about which systems are certifiable; it only removes a ray of identical answers.

Strict inequalities need a margin. Solvers work to a tolerance, so “≺ 0” is asked for as “⩽ −tI” with t a variable to be maximised. A returned t > 0 is a quantitative margin you can re-verify yourself. That last part matters more than it sounds; see §4.4.

2.5  The P-norm and the contraction factor

Once you have P, the useful number is how fast V falls. Define the P-norm ‖x‖P = (xₜPx)1/2 and the induced matrix norm

‖A‖P = maxx ≠ 0 ‖Ax‖P / ‖x‖P = σmax(RAR−1),  where P = RₜR.

‖A‖P < 1 is the same statement as AₜPA − P ≺ 0, and it says every step shrinks the P-norm by at least that factor. Keep two things in mind. First, ‖A‖P ≥ ρ(A) always: no ruler can promise faster than the spectral radius. Second, ‖A‖P is a bound on a single step, which is exactly what makes it survive switching, and ρ(A) is an asymptotic rate for a fixed A, which is exactly why it does not.

2.6  A common P for a family of matrices

Now the step that this whole study is about. Suppose the map applied at step k is not fixed but drawn from a set {A1, …, Am} by a signal you do not control. Ask for the same P to work for all of them:

P ≻ 0,  AiₜPAi − P ≺ 0   for i = 1, …, m.

Still one convex feasibility problem, just with more constraints. And what it buys is out of all proportion to the extra effort: if such a P exists then V falls at every step regardless of which mode fires, so the switched system is exponentially stable under arbitrary switching. That covers every sequence, including ones chosen adversarially against you, and ones that depend on the state. Such a P is called a common quadratic Lyapunov function.

Convex combinations are covered automatically

A common P for the vertices automatically covers every convex combination of them. Since ‖·‖P is a norm, for A(β) = (1−β)A1 + βA2 with β ∈ [0,1],

‖A(β)‖P ≤ (1−β)‖A1‖P + β‖A2‖P ≤ max(q0, q1) < 1.

Two LMIs, and you have covered a continuum. Because the bound is per-step, it is a continuum you may traverse in any order, with any β sequence. That single line is the paper’s Proposition 2.

2.7  The continuous-time counterpart

For ẋ = Ax the same derivation on V̇ = xₜ(AₜP + PA)x gives

P ≻ 0,  AₜP + PA ≺ 0.

Same structure, same convexity, same MATLAB code with one line changed. For a single stable A you do not even need a solver: P = lyap(A', Q) solves AₜP + PA = −Q in closed form, and dlyap(A', Q) does the discrete version. The solver earns its place the moment there is more than one matrix to satisfy at once, which is the next section.
