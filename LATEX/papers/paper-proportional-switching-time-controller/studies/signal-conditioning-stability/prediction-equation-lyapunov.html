1. Augmented prediction equation

Start with the physical state and then introduce the homogeneous coordinate:

x(t)∈ℝn,χ(t)=[x(t)1]∈ℝn+1.

On interval i, the augmented generator is

Fi=A˜qi=[Aqibqi00]∈ℝ(n+1)×(n+1).

Its interval transition is therefore also augmented:

φi=eFiΔt¯i=[Ψici01],Ψi=eAqiΔt¯i.

Consequently, the ordered product in the reference is itself an augmented matrix:

Φ˜=φNφN−1⋯φ1=[Φh01].

Notation bridge. The reference writes Φ = φN⋯φ1 for this augmented product. This page writes the same product as Φ̃ so that bare Φ can denote its physical n × n upper-left block. Φ̃ is not an additional propagation matrix.

With that notation, the augmented first-order prediction is

e(tN)≐Φ˜e(t0)+Γδt.

Here, e(t) ∈ ℝn+1 is the augmented error and δt = [δt1, …, δtN]T. The columns of Γ follow the same interval order:

Γ=[γ1γ2⋯γN],γi=φN⋯φi+1Fiφi⋯φ1χ¯(t0).

The symbol ≐ means equality to first order about e(t0) = 0 and δt = 0. Products such as δtie(t0) and δtiδtj are omitted.

2. Why the augmented eigenvalue at one does not obstruct stability

The lower-right entry 1 comes from the homogeneous coordinate appended to χ. It is not an additional physical state. Both the actual and nominal augmented states have last coordinate 1, so their difference is

e(t)=χ(t)−χ¯(t)=[x(t)−x¯(t)1−1]=[ex(t)0].

For nominal durations, the augmented product represents the affine one-cycle map:

Φ˜[xk1]=[Φxk+h1].

At the periodic anchor, Φx⋆ + h = x⋆. Therefore

Φ˜[x⋆1]=[x⋆1].

This explains the eigenvalue at 1. Its augmented fixed-point direction has a nonzero last coordinate and therefore cannot occur as an augmented error.

On every admissible error, the same product reduces to

Φ˜[ex0]=[Φex0].

The columns of Γ also have last coordinate zero, so duration perturbations do not leave this subspace. Stability can therefore be analyzed on the invariant physical-error subspace ℝn × {0}.

Do not test strict contraction of Φ̃ on all of ℝn+1. Project to the physical matrix Φ, or state explicitly that the Lyapunov function is positive definite only on the admissible error subspace.

3. From prediction to the closed-loop map

Project the augmented prediction onto the physical state with

Π=[In0],ι=[In0]

At the cycle boundaries, e(t0) = ιek and ek+1 = Πe(tN). Hence

ek+1≐Φek+GdδtkΦ=ΠΦ˜ι,Gd=ΠΓ

Fixed-period switching offsets change adjacent interval durations according to

δtk=Dδτk

For the raw feedback law and its conditioned application,

δτkraw=−Kek,δτkapp=−βkKek.

Substitution removes the external timing input and produces the homogeneous physical closed-loop map

ek+1=A(βk)ekA(β)=Φ−βGdDK=(1−β)Φ+βAcl,Acl=Φ−GdDK
  1. The augmented equation supplies Φ̃ and Γ.
  2. Projection supplies Φ and Gd.
  3. The timing map and feedback law supply A(β).
  4. The Lyapunov analysis is applied to A(β).

4. Stability proof strategy

The stability proof starts by restricting the augmented model to the admissible error subspace. The last augmented-error coordinate is always zero, so

Φ˜[e0]=[Φe0].

The augmented eigenvalue at 1 acts only along a coordinate that cannot occur in an augmented error. It therefore does not enter the physical stability problem.

  1. Restrict the state. Work on ℝn × {0}, where the augmented error is [eT, 0]T.
  2. Project the prediction. Use Φ = ΠΦ̃ι and Gd = ΠΓ to obtain the physical cycle-start model.
  3. Close the timing loop. Substitute δtk = Dδτk and δτk = −βkKek.
  4. Analyze the resulting matrix. Prove contraction of A(β) = Φ − βGdDK with a quadratic Lyapunov function on ℝn.

The augmented model derives the matrices. The physical closed-loop map is the object certified by Lyapunov analysis.

5. Why the endpoint tests cover every conditioning factor

Let the two endpoint matrices be

A0=Φ,A1=Acl,A(β)=(1−β)A0+βA1.

Seek one symmetric positive-definite matrix P satisfying both endpoint inequalities:

A0TPA0−P≺0,A1TPA1−P≺0.

The quadratic term for an intermediate β satisfies the exact identity

A(β)TPA(β)=(1−β)A0TPA0+βA1TPA1−β(1−β)(A1−A0)TP(A1−A0).

The last term is negative semidefinite because P is positive definite. Hence

A(β)TPA(β)−P≼(1−β)(A0TPA0−P)+β(A1TPA1−P)≺0.

The same V(e) = eTPe therefore decreases for every β ∈ [0,1] and for every time-varying sequence {βk}.

If β = 0 is admissible, the physical open-loop matrix Φ must also contract. If Φ is unstable, the proof must impose β ≥ βmin > 0 and analyze that smaller interval.

6. Lyapunov analysis and claim boundaries

Use a quadratic Lyapunov function on the physical cycle-start error:

V(e)=eTPe,P=PT>0

For a fixed conditioning factor, its one-cycle change is

ΔV=ekT(A(β)TPA(β)−P)ek

A common quadratic certificate requires

A(β)TPA(β)−P≺0,β∈[0,1]

Because A(β) lies on the segment between A(0) = Φ and A(1) = Acl, it is sufficient to find one P for which both endpoint induced norms are strictly below one:

‖Φ‖P≤q0<1,‖Acl‖P≤q1<1‖A(β)‖P≤(1−β)q0+βq1≤max(q0,q1)<1
ClaimWhat the equations support
Linearized conditioned familyExponential stability for every sequence {βk} ⊂ [0,1] when a common P exists.
Exact nonlinear cycle map near the orbitLocal exponential stability when the map is differentiable, the nominal dwell margin makes β = 1 near the orbit, and Acl is Schur.
Exact nonlinear map for large errorsNot established by this Lyapunov argument. Large-error behavior remains simulation evidence.

Conclusion. The prediction equation belongs in the stability development as the source of the physical cycle matrices. The Lyapunov inequalities themselves should use A(β), not the full augmented matrix Φ̃.

7. Normalized certificate and nonlinear interpretation

The numerical certificate uses normalized physical coordinates rather than the augmented state:

zk=Sx−1ek.

The two matrices supplied to the common-P computation are

A0=Sx−1ΦSx,A1=Sx−1AclSx.

The SDP finds P = PT > 0 such that both normalized endpoint inequalities are strict. The Lyapunov function is then

V(z)=zTPz.

Connection to the exact nonlinear cycle map

The common-P result directly certifies the linearized conditioned family. A separate local argument connects the linearization to the exact nonlinear cycle map.

  1. The nominal schedule has strict dwell margin.
  2. Therefore, a neighborhood of the periodic orbit requires no conditioning and β = 1 there.
  3. The Jacobian of the exact closed-loop cycle map at the orbit is Acl.
  4. If Acl is Schur and the cycle map is continuously differentiable while mode order is preserved, the discrete-time linearization theorem gives local exponential stability.
ek+1=Aclek+O(‖ek‖2).

This establishes local stability near the periodic orbit. It does not establish global nonlinear stability while conditioning is active. Large-error behavior remains simulation evidence.
