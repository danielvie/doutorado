Important

The Lyapunov scripts do not create these matrices. They start after \(A_0\) and \(A_1\) have been calculated, then optimize a matrix \(P\) that proves their stability.

1. Plant and data

For each binary switch command \(\mathbf u=(u_1,u_2,u_3)\), the converter state is \(x=[v_{C_1},v_{C_2},i_L]^\mathsf T\) and the dynamics are

\[ \dot{x}=A_{\mathbf u}x+b_{\mathbf u}, \qquad A_{\mathbf u}= \begin{bmatrix} 0 & 0 & (u_2-u_1)/C_1\\ 0 & 0 & (u_3-u_2)/C_2\\ (u_1-u_2)/L & (u_2-u_3)/L & -R/L \end{bmatrix}, \qquad b_{\mathbf u}= \begin{bmatrix}0\\0\\Eu_3/L\end{bmatrix}. \]

The benchmark values are

\[ E=30\,\mathrm V, \quad C_1=C_2=40\,\mu\mathrm F, \quad L=10\,\mathrm{mH}, \quad R=10\,\Omega. \] \[ \frac{1}{C_1}=\frac{1}{C_2}=25000, \quad \frac{1}{L}=100, \quad \frac{R}{L}=1000, \quad \frac{E}{L}=3000. \]

The calculation uses seconds for time. The prescribed mode sequence and dwell durations are

\[ \boldsymbol\Omega=(000,001,011,111,010,000,100,111,100), \] \[ \bar{d}=\begin{bmatrix} 63.889183506119 & 23.667599375879 & 22 & 22.981276969501 & 22 & 63.672008257925 & 22.170089330625 & 23.447427391152 & 22.172415168799 \end{bmatrix}\,\mu\mathrm s. \]

The dwell vector sums to \(286\,\mu\mathrm s\). In MATLAB, use diff(boundary_us) * 1e-6 before calling expm.

2. Build the mode matrices

Take decimal mode 1 as an example. Its three-bit representation is \(001\), so \(u_1=0\), \(u_2=0\), and \(u_3=1\). Substituting into the plant equation gives

\[ A_{001}= \begin{bmatrix} 0 & 0 & 0\\ 0 & 0 & 25000\\ 0 & -100 & -1000 \end{bmatrix}, \qquad b_{001}= \begin{bmatrix}0\\0\\3000\end{bmatrix}. \]

The cycle uses the following mode matrices. The table lists only their nonzero entries because all omitted entries are zero.

Why \(b_{\mathbf u}\) is not needed for \(\Phi\)

The vector \(b_{\mathbf u}\) changes the particular trajectory. The derivative of the flow with respect to its incoming state depends only on \(A_{\mathbf u}\). It reappears when we calculate the switching-time matrix \(\Gamma_\tau\).

3. Construct \(\Phi\)

First define \(\Phi\). Let \(\mathcal P(x,\delta\tau)\) be the exact one-cycle map. With the nominal schedule, the physical state-transition matrix is the derivative. This is the first object in equation (15) of the article, not the normalized matrix \(A_0\).

\[ \Phi:=\left.\frac{\partial\mathcal P(x,\delta\tau)}{\partial x}\right|_{x=x^\star,\;\delta\tau=0}\in\mathbb R^{3\times3}. \] \[ e_{k+1}=\Phi e_k \quad\text{when the schedule is fixed.} \]

So \(\Phi\) is not a gain and it is not yet a numerical matrix. It is the name of the derivative we are about to calculate.

Step 1: calculate one interval

For interval \(i\), write \(A_i:=A_{\omega_i}\) and \(b_i:=b_{\omega_i}\). The exact affine flow over the dwell \(\bar d_i\) is

\[ x_{i+1}=e^{A_i\bar d_i}x_i+ \int_0^{\bar d_i}e^{A_i(\bar d_i-s)}b_i\,\mathrm ds. \] \[ T_i:=\frac{\partial x_{i+1}}{\partial x_i}=e^{A_i\bar d_i}. \]

The integral changes the nominal state, but its derivative with respect to \(x_i\) is zero. Therefore \(T_i\) contains only \(A_i\).

Step 2: form the nine-interval product

Use the mode order \((000,001,011,111,010,000,100,111,100)\). In the article's notation, equation (15) writes the physical propagation and the dwell-sensitivity matrix together:

\[ \Phi=e^{A_{\omega_9}\bar d_9}\cdots e^{A_{\omega_1}\bar d_1}, \qquad G_d=\Pi\begin{bmatrix}\widetilde g_1&\cdots&\widetilde g_9\end{bmatrix}. \]

For the present calculation, only the first expression is needed. The shorthand \(A_i=A_{\omega_i}\) turns it into:

\[ \begin{aligned} \Phi & =T_9T_8T_7T_6T_5T_4T_3T_2T_1\\ & =e^{A_{100}\bar d_9}e^{A_{111}\bar d_8}e^{A_{100}\bar d_7}e^{A_{000}\bar d_6} e^{A_{010}\bar d_5}e^{A_{111}\bar d_4}e^{A_{011}\bar d_3}e^{A_{001}\bar d_2}e^{A_{000}\bar d_1}. \end{aligned} \]

The first interval is the rightmost factor because it acts first. In MATLAB, left-multiply each new transition:

Phi = eye(3);
for i = 1:9
    T_i = expm(A{i} * dwell(i));
    Phi = T_i * Phi;
end

Step 3: evaluate the product

Now that \(\Phi\) has been defined and its product has been constructed, evaluate the nine exponentials. The result is

\[ \boxed{ \Phi= \begin{bmatrix} 0.999528056772 & -0.001874805700 & 0.112287480533\\ 0.001756231660 & 0.999919471340 & 0.072744632851\\ 0.000556049938 & -0.000013830104 & 0.751736931125 \end{bmatrix}} \]

\(\Phi\) is not the entire augmented matrix

The article uses augmented maps to propagate affine dynamics:

\[ F_i=\begin{bmatrix}A_i&b_i\\0&0\end{bmatrix}, \qquad E_i=e^{F_i\bar d_i}, \qquad \widetilde\Phi=E_NE_{N-1}\cdots E_1. \] \[ \widetilde\Phi= \begin{bmatrix} \Phi & h\\ 0 & 1 \end{bmatrix}. \]

Here \(\widetilde\Phi\) is the full \(4\times4\) augmented propagation matrix. The \(\Phi\) used above is its upper-left \(3\times3\) block, and it is the physical matrix in equation (15) of the article.

Evaluating the nine exponentials in seconds reproduces this matrix. The maximum absolute difference from the generated project matrix is approximately \(5.6\times10^{-17}\).

4. Normalize \(\Phi\) to obtain \(A_0\)

The controller compares voltage and current errors in normalized coordinates:

\[ z=S_x^{-1}e, \qquad S_x=\operatorname{diag}(10,20,1). \]

The physical open-loop error map is \(e_{k+1}=\Phi e_k\). Substitute \(e_k=S_xz_k\):

\[ z_{k+1}=S_x^{-1}e_{k+1}=S_x^{-1}\Phi S_xz_k. \] \[ \boxed{A_0=S_x^{-1}\Phi S_x} \]

Using the \(\Phi\) shown above gives

\[ A_0= \begin{bmatrix} 0.999528056772 & -0.003749611399 & 0.011228748053\\ 0.000878115830 & 0.999919471340 & 0.003637231643\\ 0.005560499383 & -0.000276602072 & 0.751736931125 \end{bmatrix}. \]

Because \(S_x\) is diagonal, the entries satisfy \((A_0)_{ij}=(s_j/s_i)\Phi_{ij}\). For example,

\[ (A_0)_{12}=\frac{20}{10}(-0.001874805700)=-0.003749611399. \]

5. Construct \(\Gamma_\tau\)

To obtain \(A_1\), we need the effect of moving each of the eight interior switching instants. This effect depends on the affine dynamics, so first propagate the nominal orbit.

Nominal boundary states

Append a constant state coordinate:

\[ X=\begin{bmatrix}x\\1\end{bmatrix}, \qquad F_i=\begin{bmatrix}A_i&b_i\\0&0\end{bmatrix}, \qquad X_{i+1}=e^{F_i\bar d_i}X_i. \]

Starting at \(x^\star=[9.9247,19.2928,0.9823]^\mathsf T\), the boundary states are

Move one boundary

Moving boundary \(i\) later gives mode \(i\) extra time and mode \(i+1\) less time. The first-order change is the vector-field jump at that boundary:

\[ \Delta f_i =f_i(\bar x_i)-f_{i+1}(\bar x_i) =(A_i-A_{i+1})\bar x_i+b_i-b_{i+1}. \] \[ \boxed{\Gamma_{\tau,i}=T_NT_{N-1}\cdots T_{i+1}\,\Delta f_i, \qquad i=1,\ldots,8.} \]

Thus \(b_i\) enters \(\Gamma_\tau\) through the vector-field jump and through the nominal boundary states. It did not enter \(\Phi\).

The controller normalizes timing with \(t_s=10\,\mu\mathrm s\):

\[ B=S_x^{-1}\Gamma_\tau t_s. \] \[ B=\begin{bmatrix} -0.000084969 & -0.023257145 & 0.024113314 & -0.025774595 & 0.023896539 & 0.024382377 & -0.022279465 & 0.023451144\\ -0.011559392 & 0.011784571 & 0.000284499 & 0.011849947 & -0.012395354 & 0 & 0 & 0\\ -0.008576838 & -0.007817609 & -0.008178416 & 0.017533827 & 0.008327507 & -0.009243155 & -0.019160134 & 0.019628806 \end{bmatrix}. \]

6. Compute \(A_1\)

In normalized coordinates, the linearized timing-input model is

\[ z_{k+1}=A_0z_k+Bv_k. \]

The aggressive feedback gain comes from discrete LQR:

\[ Q=I_3, \qquad R_n=0.001I_8, \qquad K=\operatorname{dlqr}(A_0,B,Q,R_n), \qquad v_k=-Kz_k. \] 
K = dlqr(A0, B, eye(3), 0.001 * eye(8));
v = -K * z;

The gain returned for this benchmark is approximately

\[ K=\begin{bmatrix} -2.445469 & -13.155561 & -2.035081\\ -2.634530 & 9.517183 & -2.728678\\ 6.969096 & 7.524916 & -4.020499\\ -4.887290 & 5.794366 & 6.361237\\ 2.614725 & -10.167997 & 2.932988\\ 7.034635 & 7.376775 & -4.385349\\ -4.681720 & -3.298990 & -5.772464\\ 4.962024 & 3.539675 & 5.885109 \end{bmatrix}. \]

Substitute \(v_k=-Kz_k\) into the plant:

\[ z_{k+1}=(A_0-BK)z_k, \qquad \boxed{A_1=A_0-BK}. \] \[ A_1=\begin{bmatrix} 0.189357323 & 0.090979279 & -0.021282550\\ 0.091998671 & 0.538853592 & -0.025611841\\ -0.037173447 & -0.058593575 & 0.277454698 \end{bmatrix}. \]

Signal conditioning applies only a scalar \(\beta\) to the raw input:

\[ v_k^{\mathrm{app}}=-\beta_kKz_k, \qquad A(\beta_k)=A_0-\beta_kBK=(1-\beta_k)A_0+\beta_kA_1. \]

There are two unrelated matrices called P in the broader workflow

dlqr internally computes a Riccati solution to design \(K\). The stability scripts later compute a Lyapunov matrix \(P\) with an SDP. The Riccati solution and the Lyapunov certificate are different matrices.

7. Complete MATLAB calculation

This listing starts from the converter equation and reconstructs \(A_0\) and \(A_1\). It does not load a saved result. It requires Control System Toolbox for dlqr.

%% Physical parameters
E  = 30;
C1 = 40e-6;
C2 = 40e-6;
L  = 10e-3;
R  = 10;

%% Nominal schedule
modes = [0, 1, 3, 7, 2, 0, 4, 7, 4];
boundary_us = [0, 63.889183506119, 87.556782881998, ...
    109.556782881998, 132.538059851499, 154.538059851499, ...
    218.210068109424, 240.380157440049, 263.827584831201, 286];
dwell = diff(boundary_us) * 1e-6;
x_star = [9.9247; 19.2928; 0.9823];
N = numel(modes);

%% Build A_i, b_i, interval transitions, and nominal boundary states
A = cell(1, N);
b = cell(1, N);
T = cell(1, N);
x_bar = zeros(3, N + 1);
x_bar(:, 1) = x_star;

for i = 1:N
    bits = dec2bin(modes(i), 3) - '0';
    u1 = bits(1);
    u2 = bits(2);
    u3 = bits(3);

    A{i} = [
        0,          0,          (u2-u1)/C1;
        0,          0,          (u3-u2)/C2;
        (u1-u2)/L,  (u2-u3)/L,  -R/L];
    b{i} = [0; 0; E*u3/L];

    F = [A{i}, b{i}; zeros(1, 4)];
    interval_map = expm(F * dwell(i));
    T{i} = interval_map(1:3, 1:3);

    next = interval_map * [x_bar(:, i); 1];
    x_bar(:, i + 1) = next(1:3);
end

%% Phi and A0
Phi = eye(3);
for i = 1:N
    Phi = T{i} * Phi;
end
Sx = diag([10, 20, 1]);
A0 = Sx \ Phi * Sx;

%% Gamma_tau and normalized timing matrix B
Gamma_tau = zeros(3, N - 1);
for i = 1:(N - 1)
    post_transition = eye(3);
    for j = (i + 1):N
        post_transition = T{j} * post_transition;
    end

    field_jump = (A{i} - A{i + 1}) * x_bar(:, i + 1) ...
        + b{i} - b{i + 1};
    Gamma_tau(:, i) = post_transition * field_jump;
end

timing_scale = 10e-6;
B = Sx \ Gamma_tau * timing_scale;

%% LQR and A1
K = dlqr(A0, B, eye(3), 0.001 * eye(8));
A1 = A0 - B * K;

%% Checks
assert(abs(sum(dwell) - 286e-6) < 1e-15);
assert(norm(x_bar(:, end) - x_star, inf) < 1e-10);
assert(max(abs(eig(A0))) < 1);
assert(max(abs(eig(A1))) < 1);

disp(Phi)
disp(A0)
disp(A1)

Calculation chain

\[ (A_{\mathbf u},b_{\mathbf u}) \longrightarrow T_i=e^{A_i\bar d_i} \longrightarrow \Phi=T_9\cdots T_1 \longrightarrow A_0=S_x^{-1}\Phi S_x \longrightarrow \Gamma_\tau,B,K \longrightarrow A_1=A_0-BK. \]

The stability scripts begin at the \(A_0\) and \(A_1\) steps. Their SDP finds a Lyapunov certificate for the matrices that this chain produces.
