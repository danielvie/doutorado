6 · Scope of the result, and reproduction

What is proved, what is not, and how to rerun it

A Lyapunov certificate is a narrow, exact statement, and most of the trouble it causes comes from reading it wider than it is. For the result in §5, the line falls here.

ProvedNot proved
Every A(β) on the segment contracts in ‖·‖P by at most q = {{paper.q0|.6f}}, for arbitrary and state-dependent β sequences. Anything about the nonlinear remainder of the cycle map away from the anchor. The segment result is a statement about the linearization.
The conditioner returns the largest feasible β, preserves the cycle period exactly, and preserves the direction of the raw action. That per-component clipping would also have worked. It would not; see §5.7.
Local exponential stability of the anchor for the exact map, in the neighbourhood where conditioning is inactive and the Jacobian is Acl. A region of attraction. The neighbourhood is shown to exist; it is not estimated.
Stability of the family in the linearized model even when the open loop is the only thing acting. Performance. q is set by the open-loop endpoint and describes the case where the controller never corrects.
Nothing about hardware. Timer quantisation, transport delay, dead time, state estimation, parameter uncertainty, execution time. None of these are in the model.

The habit worth building is to state the family the certificate covers before quoting the number. “q = {{paper.q0|.6f}} over the segment between Φ and Acl, for any β sequence in [0,1]” is a claim someone can check. “The system is stable” is not.

6.1  Reproducing these results

From the repository root, with YALMIP and SeDuMi on the MATLAB path:

% the worked example of sections 3 and 4
cd studies/lyapunov
generic_example

% the paper's certificate, rebuilt from the generated results
paper_certificate

% regenerate the data embedded in this page, then rebuild it
export_study_data
%   $ python build.py

paper_certificate reads results/paper_results.mat, so scripts/generate_results.m has to have been run first. It re-solves the semidefinite program from scratch and reports the Frobenius distance to the stored P; on this machine that distance is zero, because SeDuMi is deterministic for this problem.
