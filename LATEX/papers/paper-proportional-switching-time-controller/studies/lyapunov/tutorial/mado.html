1. One energy function for every conditioning factor

The claim, precisely

The applied timing action is δτ=−βKe. Thus the physical, linearized cycle matrix lies on the segment between the open-loop cycle matrix and the raw closed-loop matrix. If the same positive-definite P gives strict Lyapunov decrease at both endpoints, it gives uniform decrease throughout that segment, even when β changes with the state.

A(β)=(1−β)A0+βA1,0≤β≤1 V(z)=zTPz,AiTPAi−P≺0,i∈{0,1}
Scope: global exponential stability of this conditioned linearized model. The exact nonlinear switching-time map retains only a local guarantee unless its remainder is bounded on a certified region.

4. Project onto physical error dynamics

The fourth state is 1; the fourth error is 0.
χ=[x1],χ¯=[x¯1],ε=χ−χ¯=[e0]. A strict Lyapunov test over all of ℝ⁴ asks an artificial, invariant coordinate to decay. That problem is infeasible, not merely poorly conditioned.
Π=[I30]∈R3×4,ι=[I30T]∈R4×3 ε=ιe,e=Πε,Πι=I3 Φ=ΠΦ~ι,Gd=ΠΓ~d ek+1≈Φek+Gdδdk

Because Φ~=[Φh0T1], its spectrum contains 1. Any hypothetical strict 4-dimensional certificate would have to decrease along an eigenvector with eigenvalue 1, which is impossible. On ε=ιe, however, Φ~ι=ιΦ and Γ̃d has zero last row. The reduced model exactly represents the first-order physical error dynamics.

Map independent switching offsets into coupled dwell changes.

δd=Dδτ,D∈R9×8 Dij={1,i=j,−1,i=j+1,0,otherwise Γτ=ΠΓ~dD∈R3×8 ek+1=Φek+Γτδτk+O(‖[ekδτk]‖2)

Delaying switching instant j lengthens dwell j and shortens dwell j+1. Therefore column j of Γτ is Π(γⱼ − γⱼ₊₁). Every column of D sums to zero, preserving the period.

6. Find and verify the common P

Let P be a symmetric 3 × 3 decision variable. Maximize a shared Euclidean decrease margin η while fixing the arbitrary scale of P.

Maximize η over symmetric P and scalar η, subject to:

tr(P)=3P⪰10−7I3P−A0TPA0⪰ηI3P−A1TPA1⪰ηI3

These constraints are affine in P because both endpoint matrices are fixed. A positive optimum with independently positive eigenvalues certifies strict decrease. The trace constraint prevents unbounded rescaling; maximizing η is not the same as optimizing the sharpest exponential rate.

Equivalent MATLAB CVX formulation

The numbers above were computed with Python CVXPY and CLARABEL, not MATLAB CVX. After constructing the same normalized A₀ and A₁, the equivalent CVX model is:

cvx_begin sdp
    variable P(3,3) symmetric
    variable eta
    maximize(eta)
    subject to
        trace(P) == 3;
        P >= 1e-7*eye(3);
        P - A0'*P*A0 >= eta*eye(3);
        P - A1'*P*A1 >= eta*eye(3);
cvx_end
% Independently inspect the returned matrices, not just cvx_status.
P = (P + P')/2;
Q0 = P - A0'*P*A0;
Q1 = P - A1'*P*A1;
[eig(P), eig((Q0+Q0')/2), eig((Q1+Q1')/2)]

If infeasible, do not conclude that the actual conditioned controller is unstable. A common quadratic certificate for arbitrary β sequences is a sufficient, potentially conservative test. If A₀ is not Schur, this strict full-interval test cannot succeed.

7. Prove uniform exponential stability

1. Apply the Schur complement.

ATPA−P≺0 ⟺M(A)=[−PATA−P−1]≺0,P≻0

The lower-right block is negative definite. Its Schur complement is −P−AT(−P)A=ATPA−P. The inverse form is valid for this proof, but is not an LMI in the unknown P.

For numerical work an inverse-free equivalent is [PATPPAP]≻0. The direct inequalities used above are already LMIs.

2. Use the same P at both endpoints.

M(A(β))=(1−β)M(A0)+βM(A1)≺0

A convex combination of the negative-definite endpoint block matrices remains negative definite for every β ∈ [0,1]. Different endpoint matrices P₀ and P₁ would not give this identity.

3. Obtain a uniform, not merely pointwise, decrease.

Q(β)=P−A(β)TPA(β)=(1−β)Q0+βQ1+β(1−β)(A1−A0)TP(A1−A0)⪰q*I3 q*=min{λmin(Q0),λmin(Q1)}>0

The extra quadratic term is positive semidefinite. This identity also proves the endpoint result directly, without a block matrix.

4. Convert decrease into exponential convergence.

V(zk+1)−V(zk)≤−q*‖zk‖2 V(zk+1)≤[1−q*λmax(P)]V(zk) ‖zk‖≤κ2(P)rk‖z0‖ r=1−q*λmax(P)<1

For this certificate, q* = 2.91190432e-4, r = 0.9999389541, and √κ₂(P) = 21.867101. The uniform bound includes β = 0, so it can be much slower than the actual conditioned transient.

The inequality holds at each step for whichever β is selected. It requires neither constant β nor a derivative of the conditioner. It therefore covers state-dependent conditioning and arbitrary time variation.

5. Combine stability with dwell feasibility.

The conditioner guarantees d¯+Dδτapp≥dmin1 at each cycle. The common-P theorem guarantees convergence of the conditioned linearized model even outside the raw-action invariant region. Since strict nominal margins put a neighborhood of z = 0 inside the raw-feasible region, convergence implies that β eventually stays at 1.

6. Keep the nonlinear claim separate.

The exact map is z+=A(β(z))z+r(z), with r(z)=O(‖z‖2) near the anchor. Its Lyapunov increment has the additional terms 2zTATPr+rTPr. They are locally dominated by the strict quadratic decrease, but no global bound is established here. Near the anchor the conditioner is inactive and the original local nonlinear argument also applies.
