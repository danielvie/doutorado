# Terminology

Status: descriptive glossary
Source of truth: `CONTEXT.md`
Read when: a term in the paper or research notes is ambiguous

The project uses the following distinctions.

## Plant and reference behavior

- **Switched-affine plant**: a continuous-time plant whose affine state dynamics are selected from a finite set during each mode interval.
- **Switch state**: the simultaneous binary state of the converter switches.
- **Physical mode ID**: the zero-based integer encoding of a converter switch state.
- **Dynamics index**: the one-based identifier used to select the dynamics for an interval. It is not necessarily a physical mode ID.
- **Mode interval**: a contiguous part of a switching cycle governed by one affine dynamics pair.
- **Reference periodic trajectory**: the time-parameterized periodic state evolution generated by the nominal schedule.
- **Target limit cycle**: the closed state-space behavior traced by the reference periodic trajectory.
- **Desired operating point**: the average physical-state objective used to select a reference trajectory. It is not generally a point on the limit cycle.
- **Cycle anchor**: the selected point on the reference periodic trajectory at the start of every cycle and the fixed point of the nominal one-cycle map.
- **Cycle-start state**: the actual state at the start of one particular cycle.
- **Cycle-start error**: the difference between the cycle-start state and the cycle anchor.

## Schedule

- **Switching cycle**: one complete traversal of the repeating schedule.
- **Cycle boundary**: a scheduled time separating adjacent intervals, including the cycle start and end.
- **Switching instant**: an interior cycle boundary at which the switch state changes.
- **Nominal switching schedule**: the ordered intervals and boundary times of the uncorrected cycle.
- **Switching-instant offset**: a signed displacement of an interior nominal switching instant.
- **Dwell duration**: elapsed time between consecutive cycle boundaries.
- **Minimum dwell duration**: the lower bound imposed on every dwell.
- **Cycle period**: elapsed time from the cycle start to the cycle end.

## Controller

- **One-cycle map**: the exact mapping from a cycle-start state and applied switching-instant offsets to the next cycle-start state.
- **One-cycle linearized model**: the first-order approximation of the one-cycle map around the cycle anchor and nominal schedule.
- **Nominal cycle matrix**: the linear state-transition matrix of the nominal one-cycle map without timing feedback.
- **Raw closed-loop matrix**: the linear one-cycle matrix obtained when the complete raw switching-instant offset is applied without dwell-time conditioning.
- **Raw switching-instant offset**: the complete vector requested by the feedback law before conditioning.
- **Applied switching-instant offset**: the vector sent to the plant after conditioning.
- **Proportional switching-time controller**: a static cycle-start state-feedback law that maps error linearly to raw switching-instant offsets.
- **Dwell-time conditioning**: uniform radial contraction of the complete raw offset vector by the largest feasible scalar.
- **Conditioning factor**: the scalar in the interval from zero to one that multiplies the complete raw vector.
- **Conditioned linearized matrix family**: the family of one-cycle linearized matrices produced by all conditioning factors from zero to one, ranging from the nominal cycle matrix to the raw closed-loop matrix.
- **Raw-action admissible region**: errors for which the raw action already satisfies all dwell constraints.
- **Fixed-conditioning-factor feasible region**: for a specified conditioning factor, errors whose scaled applied action satisfies all dwell constraints in the current cycle. At a factor of one, it equals the Raw-Action Admissible Region.
- **Maximal invariant Raw-Action Admissible Region**: the largest subset of the Raw-Action Admissible Region that remains inside it under repeated application of the Raw Closed-Loop Matrix.

Use this glossary together with `CONTEXT.md`. Do not replace the defined terms with near-synonyms when the distinction matters.
