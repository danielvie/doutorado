## Main-text figures

All four PDFs live under `latex/figures/`.

1. `reference_schedule_orbit.pdf`, reconciled reference schedule, periodic states, and cycle averages. Generated by `paper.export_figures`.
2. `trajectory_comparison.pdf`, dense continuous-time physical-state paths for conditioned feedback and open loop over the same 100 cycles, overlaid on one 3D set of axes. Rendered by `paper.plot_trajectories` from the data produced by `paper.export_trajectories`.
3. `conditioned_control_response.pdf`, first 25 cycles of error norms, conditioning factors, raw/applied offsets, and minimum dwells. Generated by `paper.export_figures`.
4. `open_loop_convergence.pdf`, three physical-state histories sampled at cycle starts against logarithmic time, alongside a 3D view of the dense early transient and faded later cycle-start samples. The reference cycle and final within-cycle trajectory are drawn once. Rendered by `paper.plot_trajectories`.

The short-run 3D paths use exact within-interval samples, not only polygons connecting switching-boundary states. The long-run view deliberately replaces later complete cycles with selected actual cycle-start points. These are not the fixed reference anchor or cycle averages. The MAT record retains every cycle start; figures and the CSV use selected samples. Logarithmic time plots omit cycle zero.

## Tables and displayed certificate

- `tab:parameters` contains converter, schedule, normalization, and LQR parameters.
- `tab:results` contains spectral radii, conditioning statistics, dwell durations, and error-threshold cycles.
- `eq:numerical-p` and `eq:numerical-margins` display the common Lyapunov matrix and directly checked eigenvalue margins.

The manuscript uses generated values from `latex/metrics.tex` and `latex/lyapunov_metrics.tex`.

## Supporting figures

`latex/figures/invariant_raw_action_region.pdf` remains generated evidence for the supporting region analysis but is not included in the manuscript. `results/figures/first_cycle_conditioning.pdf` is an auxiliary detailed dwell view; `results/figures/conditioned_control_response.pdf` is the source copy of the promoted main-text response figure.

The older standalone comparisons remain under `studies/trajectory-comparison/results/`. Older experiments are preserved under `archive/legacy-experiments/figures/`.
