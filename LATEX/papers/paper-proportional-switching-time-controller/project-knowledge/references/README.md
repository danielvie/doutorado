# Reference summaries

Status: descriptive reference index
Source of truth: `references.bib`, the cited papers, and the project's research notes
Read when: studying prior work or preparing a literature synthesis

## Purpose

The files in this directory summarize what an external source says. They do not decide whether a source is novel relative to this project, whether it should be cited in a future version, or whether its method is a suitable comparison. Those questions belong in a dated file under `../syntheses/`.

## Summary format

Each source summary records:

- bibliographic identity;
- problem;
- system or setting;
- approach;
- main contribution;
- evidence;
- assumptions and limitations;
- concepts or equations useful for later reading;
- source pointers.

The summary describes the source. A separate synthesis should be used for comparisons, project relationships, novelty judgments, or recommendations.
