# Gilbert and Tan (1991)

Status: descriptive source summary
BibTeX key: `gilbert1991maximal`
Source record: `latex/references.bib`; DOI: `10.1109/9.83532`
Read when: reviewing maximal admissible sets for constrained linear systems

## Problem

The paper studies linear systems subject to pointwise state and control constraints and characterizes the initial conditions for which those constraints remain satisfied for all future time.

## Approach

It defines the maximal output-admissible set and develops an iterative construction based on successive constraint preimages. Under stated assumptions, the iteration reaches a finitely determined polyhedral set.

## Use in this project

The paper supports the preimage iteration used to compute the maximal positively invariant subset of the Raw-Action Admissible Region. In this article, the constrained output is the raw dwell vector and the autonomous dynamics are the linearized Raw Closed-Loop Matrix.

## Limit

This reference does not certify the conditioned dynamics outside the invariant raw-action region or the exact nonlinear one-cycle map.
