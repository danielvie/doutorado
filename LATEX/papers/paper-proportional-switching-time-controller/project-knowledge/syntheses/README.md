# Provisional syntheses

Status: process description
Read when: recording a question-specific interpretation for a future thread

This directory stores analyses that go beyond description. A synthesis may compare references, assess how a method relates to this project, examine novelty, weigh evidence, or propose a possible direction.

Those conclusions are provisional. A new thread should inspect the underlying project and reference summaries before reusing them.

## Naming

Use a date and a question:

```text
YYYY-MM-DD-topic.md
```

Examples:

- `2026-08-27-research-landscape.md`
- `2026-08-30-switching-time-literature.md`
- `2026-09-02-conditioner-novelty.md`

## Suggested format

```markdown
# Question or topic

Status: provisional synthesis
Date: YYYY-MM-DD

## Question

What is being investigated?

## Sources considered

- `references/...`
- `project/...`
- relevant source files outside this directory

## Observations

What do the sources say?

## Comparisons or relationships

How might the information relate to the project for this question?

## Uncertainties

What remains unverified, ambiguous, or dependent on author intent?

## Provisional conclusion

What currently seems likely, and what should be reconsidered later?
```

Do not move a conclusion into a neutral reference or project description merely because it has appeared in several syntheses. If a conclusion becomes an explicit project decision, record that transition separately and only with author agreement.
