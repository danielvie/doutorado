Como escolher uma função de Lyapunov

Uma função de Lyapunov é uma régua que mede quanta distância resta até o equilíbrio. Vamos escolher essa régua pela física, por uma forma quadrática e por otimização convexa.

1. A ideia antes da álgebra

Considere o sistema autônomo contínuo

ẋ = f(x),    x ∈ ℝⁿ

e suponha que o equilíbrio de interesse seja a origem, f(0) = 0. Para um equilíbrio x⋆ diferente de zero, use o erro z = x − x⋆ e faça a análise em z = 0.

V não é um número fixo. É uma função que atribui um número a cada estado. Queremos que ela tenha um mínimo estrito no equilíbrio e diminua ao longo das trajetórias.

V(0) = 0,    V(x) > 0 para x ≠ 0,    dV/dt = ∇V(x)ᵀf(x) < 0 para x ≠ 0.

As duas primeiras condições dizem que V é positiva definida. A terceira diz que ela é estritamente decrescente. Se V é continuamente diferenciável e essas condições valem em uma vizinhança do equilíbrio, temos estabilidade assintótica nessa vizinhança.

O que o certificado prova

Os subníveis

Ωc = { x : V(x) ≤ c }

são candidatos a regiões invariantes. O alcance da conclusão depende do domínio onde as desigualdades foram verificadas. Local não significa global.

Quando a derivada é apenas semidefinida

Se a física fornece apenas dV/dt ≤ 0, a energia não aumenta, mas isso sozinho não prova convergência. Escolha um subnível compacto e positivamente invariante Ωc. Pelo princípio de invariância de LaSalle, as trajetórias se aproximam do maior conjunto invariante contido em {x ∈ Ωc : dV/dt = 0}. Se esse conjunto for apenas o equilíbrio, há convergência.

2. Método 1: usar a física e a energia

Comece por este método quando o sistema tem energia armazenada e dissipação identificáveis. Energia cinética, potencial, de indutores, de capacitores e funções de armazenamento termodinâmicas já têm interpretação física. Escreva a energia relativa ao equilíbrio e calcule sua derivada.

Exemplo numérico: pêndulo amortecido

Considere um pêndulo com ângulo θ, velocidade angular ω, coeficiente de amortecimento normalizado b/I = 0.8 e coeficiente gravitacional normalizado ω₀² = mgl/I = 4:

θ̇ = ω,    ω̇ = −4 sin(θ) − 0.8ω.

O equilíbrio inferior é (θ,ω) = (0,0). A energia relativa a esse ponto é

V(θ,ω) = ½ω² + 4(1 − cos θ).

O primeiro termo é energia cinética. O segundo é energia potencial, escolhido para valer zero no ponto mais baixo.

Positividade e derivada

Como ω² ≥ 0 e 1 − cos θ ≥ 0, temos V ≥ 0. Perto de θ = 0, a igualdade só ocorre em (θ,ω) = (0,0).

dV/dt = 4 sin(θ) θ̇ + ωω̇
dV/dt = 4 sin(θ)ω + ω[−4 sin(θ) − 0.8ω] = −0.8ω² ≤ 0.

A gravidade troca energia cinética por potencial e vice-versa. Esses termos se cancelam. O amortecedor é responsável pela perda líquida.

Um estado numérico

Para θ(0)=0.8 rad e ω(0)=0.6 rad/s,

V(0) = ½(0.6)² + 4[1 − cos(0.8)] ≈ 1.3932,
dV/dt(0) = −0.8(0.6)² = −0.288.

A energia está diminuindo naquele instante. A derivada é semidefinida, então usamos LaSalle. Para um subnível com 0 < c < 8, no componente que contém θ=0, dV/dt=0 implica ω=0. A invariância exige também ω̇ = −4 sin θ = 0, deixando apenas θ=0 nesse componente.

Limite do método

A energia é periódica em θ. Ela zera nos equilíbrios inferiores θ=2kπ; os superiores estão em θ=(2k+1)π e têm energia 8. Não conclua estabilidade global do ponto (0,0) sem declarar o domínio.

3. Método 2: escolher uma forma quadrática

Para um sistema linear contínuo

ẋ = Ax,

uma escolha natural é

V(x) = xᵀPx,    P = Pᵀ ≻ 0.

Uma forma sistemática de escolher P é fixar Q = Qᵀ ≻ 0 e resolver

AᵀP + PA = −Q.

Se A for Hurwitz, todos os seus autovalores terão parte real negativa, e a equação terá uma única solução P ≻ 0 para cada Q ≻ 0.

Exemplo numérico: sistema linear genérico

Use

A = [ −1   2
    −3  −4 ],    Q = I.

Os autovalores são −2.5 ± 1.9365i. Escreva P = [[p,q],[q,r]] e resolva a equação de Lyapunov:

−2p − 6q = −1
2p − 5q − 3r = 0
4q − 8r = −1.

A solução é

P = [ 0.35  0.05
    0.05  0.15 ].

Ela é positiva definida porque 0.35 > 0 e det(P) = 0.35·0.15 − 0.05² = 0.05 > 0. Assim,

V(x₁,x₂) = 0.35x₁² + 0.10x₁x₂ + 0.15x₂².

Verificar a queda

dV/dt = xᵀ(AᵀP + PA)x = −xᵀx = −(x₁²+x₂²) < 0 para x ≠ 0.

Para x(0)=[1,−1]ᵀ, V(x(0))=0.40 e dV/dt(x(0))=−2. Os autovalores de P são aproximadamente 0.1382 e 0.3618, logo

0.1382‖x‖² ≤ V(x) ≤ 0.3618‖x‖²,
dV/dt ≤ −(1/0.3618)V ≈ −2.7639V.

Portanto, V(t) ≤ V(0)e^(−2.7639t). A taxa é uma garantia, não necessariamente a taxa exata de cada trajetória.

4. Método 3: obter V por otimização convexa

Para uma matriz A fixa, as condições

P ≽ εI,    AᵀP + PA ≼ −Q

são afins em P. O conjunto viável é convexo. Minimizar trace(P) apenas escolhe uma solução específica dentro desse conjunto; a estabilidade vem das desigualdades.

Exemplo numérico: oscilador amortecido

Use A=[[0,1],[-2,-0.5]] e Q=I. Um resultado esperado ao minimizar trace(P) é

P ≈ [ 3.125  0.250
    0.250  1.500 ].

Os autovalores de P são aproximadamente 1.4625 e 3.1625. Para x₀=[1,−1]ᵀ, V(x₀)=4.125 e dV/dt(x₀)=−2.

Código MATLAB com CVX

Instale o CVX, execute cvx_setup uma vez e rode:

% escolher_P_cvx.m
clear; clc;
A = [0 1; -2 -0.5];
Q = eye(2); n = size(A,1); epsP = 1e-6;

cvx_begin sdp
    variable P(n,n) symmetric
    minimize(trace(P))
    subject to
        P >= epsP*eye(n)
        A'*P + P*A <= -Q
cvx_end

Pval = full(P);
S = A'*Pval + Pval*A;
Psy = (Pval + Pval')/2;
R = (S + Q + (S + Q)')/2;

disp('P ='); disp(Pval);
disp('eig(P) ='); disp(eig(Psy));
disp('A''*P + P*A + Q ='); disp(S + Q);

x0 = [1; -1];
fprintf('V(x0) = %.8f\n', x0'*Pval*x0);
fprintf('dV/dt(x0) = %.8f\n', x0'*S*x0);

% Verificacoes matriciais, validas para todos os estados.
tol = 1e-7;
assert(min(eig(Psy)) >= epsP - tol);
assert(max(eig(R)) <= tol);
assert(strcmp(cvx_status,'Solved') || ...
       strcmp(cvx_status,'Inaccurate/Solved'));

Espere P próximo de [[3.125,0.25],[0.25,1.5]], autovalores positivos e um resíduo A'*P + P*A + Q próximo de zero. A verificação matricial é mais forte do que testar apenas um estado.

Uma mesma V para vários modos

Para um certificado comum, use a mesma variável P e adicione uma LMI por matriz:

A1 = [0 1; -2 -0.5];
A2 = [-0.2 1; -1.4 -0.8];
Q = eye(2); n = 2; epsP = 1e-6;

cvx_begin sdp
    variable P(n,n) symmetric
    minimize(trace(P))
    subject to
        P >= epsP*eye(n)
        A1'*P + P*A1 <= -Q
        A2'*P + P*A2 <= -Q
cvx_end

S1 = A1'*P + P*A1 + Q;
S2 = A2'*P + P*A2 + Q;
fprintf('residuos: %.3e, %.3e\n', max(eig(S1)), max(eig(S2)));

A exigência é mais forte do que encontrar uma matriz diferente para cada modo. Em compensação, uma única forma quadrática pode provar estabilidade para sequências de modos, inclusive sequências que dependem do estado, quando todas as LMIs são satisfeitas.

Armadilha importante

Não otimize automaticamente P e um ganho K ao mesmo tempo. Termos como P*K costumam ser bilineares e deixam de ser convexos. A etiqueta LMI só vale quando as variáveis aparecem afim nas desigualdades.

Tempo contínuo e tempo discreto não são a mesma LMI

As desigualdades anteriores são para ẋ=Ax. Para um mapa discreto xₖ₊₁=Axₖ, use a forma

AᵀPA − P ≼ −R,    R ≻ 0.

Ela também é afim em P quando A é fixa. Não substitua uma forma pela outra sem verificar o modelo.

5. Como decidir

MétodoComece aqui quandoGanhoCuidado
Física e energiaHá armazenamento e dissipação identificáveis.Interpretação física e prova não linear.dV/dt ≤ 0 pode exigir LaSalle; a prova pode ser local.
Forma quadráticaO modelo é linear ou uma linearização.Álgebra simples, taxas e elipsoides.Uma P pode não servir para vários modos.
Otimização convexaHá várias matrizes, restrições ou necessidade de automatizar.Busca sistemática de uma P comum.Inviabilidade não prova instabilidade; produtos de variáveis podem quebrar a convexidade.
  1. Localize o equilíbrio. Trabalhe com o erro em relação a ele.
  2. Procure a energia antes do solver. Ela costuma ser a melhor explicação quando existe.
  3. Para um sistema linear, tente Q=I. Resolva a equação e confira P ≻ 0.
  4. Para vários modos, escreva LMIs comuns. Use uma variável P compartilhada.
  5. Separe prova de projeto. Encontrar P certifica um sistema já definido; não escolhe automaticamente o controlador.
  6. Cheque os resíduos. Não confie apenas no status do solver.

6. Relação com o certificado do artigo

O artigo trabalha com o mapa linearizado de ciclo

eₖ₊₁ = A(βₖ)eₖ,    A(β) = (1−β)Φ + βAcl.

A função usada é a forma quadrática V(e)=eᵀPe. Uma verificação discreta possível para os extremos é

ΦᵀPΦ − P ≼ −R,
AclᵀPAcl − P ≼ −R,    R ≻ 0.

Essas desigualdades garantem que os dois extremos contraem na mesma geometria. Como a norma induzida é convexa, para 0 ≤ β ≤ 1

‖A(β)‖P ≤ (1−β)‖Φ‖P + β‖Acl‖P < 1.

Assim, uma única P cobre qualquer sequência de fatores βₖ no modelo linearizado. Isso não é uma prova global do conversor não linear. A hipótese também exige que o mapa nominal Φ contraia na mesma norma. A condicionadora ainda pode produzir instantes admissíveis quando isso falha, mas o certificado de estabilidade desaparece.

% Padrao CVX para o mapa discreto, com matrizes numericas genericas.
Phi = [0.80 0.00; 0.00 0.60];
Acl = [0.70 0.10; -0.10 0.75];
R = 0.01*eye(2); epsP = 1e-6;

cvx_begin sdp
    variable P(2,2) symmetric
    minimize(trace(P))
    subject to
        P >= epsP*eye(2)
        Phi'*P*Phi - P <= -R
        Acl'*P*Acl - P <= -R
cvx_end
A pergunta certa ao escolher V

Não pergunte apenas “qual função parece positiva?”. Pergunte: qual quantidade é zero exatamente no equilíbrio, é comparável ao tamanho do erro na região de interesse e tem uma derivada que o modelo consegue tornar negativa? A física responde quando existe uma energia clara. A álgebra responde para sistemas lineares. A otimização convexa responde quando você precisa procurar sistematicamente uma geometria comum.
