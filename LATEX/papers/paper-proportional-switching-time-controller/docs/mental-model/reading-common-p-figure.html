1. A₀z and A₁z are matrix multiplications

The article uses a three-component vector z for the scaled error at a cycle start. A₀ and A₁ are 3 × 3 matrices. Multiplying either matrix by z gives another three-component vector.

  • A₀z: the next cycle-start error predicted with no timing correction, β = 0.
  • A₁z: the next cycle-start error predicted with the full raw timing correction, β = 1.

Both calculations use the same current z. They are alternatives. The drawing does not say to visit A₀z and then A₁z.

zk+1 = A(βk) zk
A(β)z = (1 − β) A₀z + β A₁z

These are predictions of the article's linearized cycle model. The full raw correction can violate dwell constraints. The actual controller selects a feasible β; the drawing does not claim every depicted choice is an executable schedule.

Source: latex/main.tex, labels eq:endpoints, eq:conditioned-family, and eq:conditioner. The definition is z = Sₓ⁻¹(x − x★), not z = x.

2. The boundary is a chosen error level

Yes, z is on the ellipse in this drawing. The ellipse is the boundary V(z) = 1. Its interior has V < 1; the filled convex region has V ≤ 1.

The illustrator chose a current error on that level to make the comparison easy to see. It is not a required initial condition. A real initial error can have V = 0.2, V = 1, V = 4, or another nonnegative value.

The level set surrounds zero error, not zero physical voltages and current. Also, V measures error using P; it is not necessarily ordinary distance to the center.

Source: latex/main.tex, theorem thm:common-p and the paragraph referring to fig:common-p. common_p_geometry.tex places the illustrative z exactly on the chosen ellipse.

3. Your two marked arrows represent vectors

First screenshot: the gray arrow 0 → z

This is how we draw the vector z: its tail is at the origin and its tip locates the current error. It does not show the system moving from zero error to z. The current error is already z in this snapshot.

Second screenshot: the blue arrow 0 → A₁z

This represents the vector obtained by multiplying A₁ by z. Its tip is a predicted next error. Its tail is at the origin because we are drawing a vector, not because the system starts at zero.

If we wanted to draw the cycle-to-cycle update explicitly, we would connect z → A₁z. Even that connection would represent a discrete update, not the actual continuous path taken during the switching cycle.

The thick blue segment is different

It joins A₀z and A₁z. For this fixed current z, A(β)z sits somewhere on that segment. Changing β changes the predicted next error along it. It is not a path traveled over time.

The useful first distinction is an arrow representing a vector versus an arrow representing an update. The original figure leaves this convention implicit, which makes your question understandable.

Source: common_p_geometry.tex, coordinates O, z, a0, a1, ab and the corresponding drawing commands. This interpretation is checked against the manuscript's cycle equation, not inferred from arrow color.

The coordinate change has two steps

So the origin of this drawing means x = x★. The reference is a chosen point on the periodic trajectory, sampled at the start of a cycle. It is not the smallest voltage or current the converter can have. Between cycle starts the desired physical state still moves along the periodic trajectory.

Keep the multiplication idea; use "maps" instead of "projects"

Your second statement already captures the calculation. More precisely, A₁ maps the current normalized error to the predicted next normalized error for the full raw correction. A₀ does the corresponding calculation for no timing correction. These are alternatives from the same z, not successive operations.

A general matrix can rotate, stretch, or mix the components. It need not project a vector onto a line, a plane, or the ellipse boundary. Also, this picture alone does not say the full raw schedule is feasible.

What actually gets smaller?

The quantity guaranteed to decrease by this certificate is V(z) = zᵀPz, for the conditioned linearized model. V is a scalar with minimum zero at z = 0. Neither the physical state x nor its error coordinates have to decrease numerically at every cycle.

If a voltage is below its positive reference, getting closer may require that voltage to increase. Even ordinary distance in the normalized error plot can increase for one step while V decreases. The next laboratory separates those two measures.

Why this example really has a decreasing V

With P = diag(1, 9), direct multiplication gives P − AᵀPA = diag(0.91, 5). Thus V(Az) − V(z) = −0.91z₁² − 5z₂² < 0 for every nonzero z. This algebra establishes decrease for this example; running two cases alone would not prove it. The example uses the same discrete-time inequality as the article, but different matrices.

No continuous trajectory is drawn. One step means one multiplication by this illustrative A. The numbers are dimensionless. No conclusion about global nonlinear converter behavior follows from this demonstration.
