The Ratio Test

Nine constraints, one unknown. How β is computed so the applied schedule satisfies every minimum-dwell bound — exactly, in one pass, with no solver and no search.

01

What has to be true

The controller has produced a raw offset vector δτraw. We are going to apply β·δτraw instead, and we need to pick β. The requirement is that every resulting dwell duration clears the floor:

d̄ + D(β·δτraw)  ≥  dmin·1

Written out, that is nine simultaneous inequalities. It looks like a feasibility problem. It is not, and the reason is the next paragraph.

The move that makes it easy D is a linear map and β is a scalar, so it factors straight out: D(β·δτ) = β·(Dδτ) = β·q. Write q = Dδτraw for the dwell changes the controller asked for at full strength, and m = d̄ − dmin·1 for how much room each interval has. The nine inequalities become nine scalar inequalities in one unknown:
d̄ᵢ + β·qᵢ ≥ dmin   ⟺   β·qᵢ ≥ −mᵢ

Each one is a straight line in β. Because there is only one unknown, we do not have to test candidate values — we can solve each inequality outright.

02

Solve one inequality: the sign of q decides everything

To isolate β we divide by qᵢ. Dividing an inequality by a negative number flips it, so the sign of qᵢ splits the problem into three cases — and only one of them constrains anything.

qᵢ > 0
Interval grows. Then βqᵢ ≥ 0 > −mᵢ for every β ≥ 0. A longer interval can never violate a minimum. No constraint.
qᵢ = 0
Unchanged. The inequality reads 0 ≥ −mᵢ, true by the margin assumption. No constraint.
qᵢ < 0
Interval shrinks. Divide by qᵢ < 0 and the inequality flips: β ≤ mᵢ ⁄ |qᵢ|. One upper bound.

This is the structural fact the whole method rests on: every interval contributes either nothing or an upper bound. None of them ever contributes a lower bound.

03

Intersect the bounds

Every bound must hold at once, and β is confined to [0,1] by definition — never reverse the controller, never amplify it. So the admissible set is

β ∈ [0, 1]  ∩  ⋂i : qᵢ < 0  ( −∞ ,  mᵢ ⁄ |qᵢ| ]

An intersection of upper bounds with [0,1] is a closed interval [0, β*] — one connected piece, anchored at zero. Its largest element is the answer, and it is just the smallest of the bounds:

β* = min ( 1 ,   min
i : qᵢ < 0   mᵢ ⁄ |qᵢ| )

That is equation (22). A minimum over an empty set is +∞, which correctly gives β* = 1 when nothing shrinks enough to matter — the raw action was already legal and passes through untouched.

Why β* is never zero Equation (20) assumes the nominal schedule clears the floor with strict room to spare: m > 0. Every ratio mᵢ⁄|qᵢ| is therefore strictly positive, so β* > 0 always. You are guaranteed some correction gets through — the conditioner can throttle the controller but can never switch it off.

Verify the binding row is tight:

d9 = 22.172 + 0.293972·(−65.217) = 3.000 = dmin   exactly on the floor, zero slack

Every other interval finishes with room to spare. That asymmetry is maximality: the one constraint that binds is driven precisely to equality, because if it landed above the floor you could have turned β up further and used more of the controller's action.

05

Feasible and maximal — the proof

Proposition 1, in full. It is three lines and you have already seen all of them.

Feasible Take any i. If qᵢ ≥ 0 the constraint holds for all β ≥ 0, and β* ≥ 0. If qᵢ < 0 then β* is a minimum including the term mᵢ⁄|qᵢ|, so β* ≤ mᵢ⁄|qᵢ|, which is that constraint. All nine hold.
Maximal Suppose some β′ > β* were admissible. β* equals either 1 — and β′ > 1 is outside the allowed range — or some mⱼ⁄|qⱼ|, in which case β′ violates constraint j. Either way β′ is not admissible. So β* is the largest.

Two more properties come for free from β being a single non-negative scalar: the applied vector is a positive multiple of the raw one, so the direction is unchanged; and 1ᵀD = 0 gives 1ᵀ(βq) = β·0 = 0, so the period is unchanged.

06

Why this is not a search

Feasibility here is monotone in β — legal below β*, illegal above, exactly one crossing. That is precisely the condition under which bisection is valid, so a binary search would work. It would also be a waste.

Binary search

Treats feasibility as a black box you can only probe. Guess β, check all N dwells, narrow the bracket, repeat.

cost  O(N · log 1⁄ε)
result  approximate
needs  a tolerance ε

To 10−6: about 20 rounds × 9 checks ≈ 180 operations, landing near 0.293972.

The ratio test

Each constraint is linear in β, so its exact crossing point is one division. Take the smallest.

cost  O(N)
result  exact
needs  nothing

Nine divisions, landing on 0.293972 — which is what puts interval 9 at 3.000 rather than 3.000001.

The same structure explains both facts. Monotone with one crossing is what makes a search converge; linear is what lets you write the crossing point down and skip the search. You would be iterating toward a number already in closed form.

When you would need a real solver If the constraints were nonlinear in the scaling, or if the eight offsets were allowed to move independently rather than as one scaled vector. That second case is an eight-dimensional feasibility problem — a linear program — and no single scalar scan can express its answer. Collapsing to one scalar is exactly what buys the closed form.
07

The implementation

The reference version is scripts/condition_dwell_times.m. Stripped to its logic:

// q[i] < 0 means interval i shrinks and therefore constrains beta
q    = diff([0; dtau_raw; 0])        // N dwell changes from N-1 offsets
beta = 1
for i in 1..N:
    if q[i] < 0:
        beta = min(beta, (d_nom[i] - d_min) / -q[i])

dtau_app = beta * dtau_raw           // one scalar, whole vector

One pass, one branch, one division on the branch taken. No matrix inverse, no iteration, no convergence test, no tolerance to tune. This is the sense in which the method is solver-free: the online cost is a matrix–vector product for −K·e, a difference to get q, and this scan.

One guard worth keeping The reference implementation asserts m ≥ 0 on entry and asserts the applied schedule clears dmin on exit. The first checks the standing assumption of eq. (20); the second is cheap insurance against a floating-point edge at the binding constraint, where the result sits exactly on the bound by construction.
